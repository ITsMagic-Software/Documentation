# Configuring PrecomputedAtmosphereSkybox

This skybox provides a realistic atmosphere using precomputed lighting.

Sun direction and intensity position and brighten the sun. Rayleigh and Mie shape sky and haze. Ground, height, density, and resolution define the atmosphere quality.

## Steps

1. Select the POST PROCESSING object in the Objects panel.

![Select the POST PROCESSING object in the Objects panel.](/img/guides/precomputed-atmosphere-skybox/01_select-the-post-processing-object-in-the-objects-panel.png)

### Optional: Add the PrecomputedAtmosphereSkybox component

> Use this section only if the PrecomputedAtmosphereSkybox component is not already listed in the Properties panel. If it is already present, skip the actions in this section and continue with the main tutorial below.


2.1. Tap Add Component to add PrecomputedAtmosphereSkybox.

![Tap Add Component to add PrecomputedAtmosphereSkybox.](/img/guides/precomputed-atmosphere-skybox/02_tap-add-component-to-add-precomputedatmosphereskybox.png)

2.2. Open the Render category.

![Open the Render category.](/img/guides/precomputed-atmosphere-skybox/03_open-the-render-category.png)

2.3. Open the Skybox category.

![Open the Skybox category.](/img/guides/precomputed-atmosphere-skybox/04_open-the-skybox-category.png)

2.4. Select the PrecomputedAtmosphereSkybox component.

![Select the PrecomputedAtmosphereSkybox component.](/img/guides/precomputed-atmosphere-skybox/05_select-the-precomputedatmosphereskybox-component.png)

**End of optional section. Continue with the main tutorial below.**

2. Select the PrecomputedAtmosphereSkybox component to view its settings.

![Select the PrecomputedAtmosphereSkybox component to view its settings.](/img/guides/precomputed-atmosphere-skybox/06_select-the-precomputedatmosphereskybox-component-to-view-its-settings.png)

This skybox uses precomputed lighting to create a realistic atmosphere.

- **Sun direction and intensity:** Position and brightness of the sun.
- **Rayleigh and Mie settings:** Blue sky and warm haze.
- **Ground, height, and density:** Shape the atmosphere.
- **Resolution:** Sky quality.

3. PrecomputedAtmosphereSkybox settings are visible in Properties.

![PrecomputedAtmosphereSkybox settings are visible in Properties.](/img/guides/precomputed-atmosphere-skybox/07_precomputedatmosphereskybox-settings-are-visible-in-properties.png)

## Result

The PrecomputedAtmosphereSkybox component is now configured and its settings are visible in the Properties panel. You can adjust its values and preview the result in your scene.
