# Configuring GodRaysLightShafts

God Rays create visible shafts of light around bright sources.

Intensity and exposure control shafts. Decay, density, and weight shape them. Threshold chooses bright sources. Sun position and visibility control the sun.

## Steps

1. Select the POST PROCESSING object in the Objects panel.

![Select the POST PROCESSING object in the Objects panel.](/img/guides/configure-god-rays-light-shafts/01_select-the-post-processing-object-in-the-objects-panel.png)

### Optional: Add the GodRaysLightShafts component

> Use this section only if the GodRaysLightShafts component is not already listed in the Properties panel. If it is already present, skip the actions in this section and continue with the main tutorial below.


2.1. Tap Add Component to add GodRaysLightShafts.

![Tap Add Component to add GodRaysLightShafts.](/img/guides/configure-god-rays-light-shafts/02_tap-add-component-to-add-godrayslightshafts.png)

2.2. Open the Render category.

![Open the Render category.](/img/guides/configure-god-rays-light-shafts/03_open-the-render-category.png)

2.3. Open the Lighting category.

![Open the Lighting category.](/img/guides/configure-god-rays-light-shafts/04_open-the-lighting-category.png)

2.4. Select the GodRaysLightShafts component.

![Select the GodRaysLightShafts component.](/img/guides/configure-god-rays-light-shafts/05_select-the-godrayslightshafts-component.png)

**End of optional section. Continue with the main tutorial below.**

2. Select the GodRaysLightShafts component to view its settings.

![Select the GodRaysLightShafts component to view its settings.](/img/guides/configure-god-rays-light-shafts/06_select-the-godrayslightshafts-component-to-view-its-settings.png)

God Rays create visible shafts around bright light sources.

- **Intensity and exposure:** Brightness of the shafts.
- **Decay, density, and weight:** Their length, fullness, and fade.
- **Threshold:** Which bright areas can create shafts.
- **Sun position and visibility:** The sun location and contribution.

3. GodRaysLightShafts settings are visible in Properties.

![GodRaysLightShafts settings are visible in Properties.](/img/guides/configure-god-rays-light-shafts/07_godrayslightshafts-settings-are-visible-in-properties.png)

## Result

The GodRaysLightShafts component is now configured and its settings are visible in the Properties panel. You can adjust its values and preview the result in your scene.
