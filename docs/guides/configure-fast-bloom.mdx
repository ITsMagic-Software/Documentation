# Configuring FastBloom

Fast Bloom adds an efficient glow around bright parts of the image.

Intensity controls glow. Threshold chooses bright pixels. Blur size controls glow spread.

## Steps

1. Select the POST PROCESSING object in the Objects panel.

![Select the POST PROCESSING object in the Objects panel.](/img/guides/configure-fast-bloom/01_select-the-post-processing-object-in-the-objects-panel.png)

### Optional: Add the FastBloom component

> Use this section only if the FastBloom component is not already listed in the Properties panel. If it is already present, skip the actions in this section and continue with the main tutorial below.


2.1. Tap Add Component to add FastBloom.

![Tap Add Component to add FastBloom.](/img/guides/configure-fast-bloom/02_tap-add-component-to-add-fastbloom.png)

2.2. Open the Render category.

![Open the Render category.](/img/guides/configure-fast-bloom/03_open-the-render-category.png)

2.3. Open the Highlights category.

![Open the Highlights category.](/img/guides/configure-fast-bloom/04_open-the-highlights-category.png)

2.4. Select the FastBloom component.

![Select the FastBloom component.](/img/guides/configure-fast-bloom/05_select-the-fastbloom-component.png)

**End of optional section. Continue with the main tutorial below.**

2. Select the FastBloom component to view its settings.

![Select the FastBloom component to view its settings.](/img/guides/configure-fast-bloom/06_select-the-fastbloom-component-to-view-its-settings.png)

Fast Bloom adds an efficient glow to bright areas.

- **Intensity:** Glow strength.
- **Threshold:** Which bright pixels produce glow.
- **Blur size:** How widely the glow spreads.

3. FastBloom settings are visible in Properties.

![FastBloom settings are visible in Properties.](/img/guides/configure-fast-bloom/07_fastbloom-settings-are-visible-in-properties.png)

## Result

The FastBloom component is now configured and its settings are visible in the Properties panel. You can adjust its values and preview the result in your scene.
