# Configuring LensDistortion

Lens Distortion bends the image to imitate a curved camera lens.

Distortion bends the image outward or inward. Scale keeps it framed.

## Steps

1. Select the POST PROCESSING object in the Objects panel.

![Select the POST PROCESSING object in the Objects panel.](/img/guides/lens-distortion/01_select-the-post-processing-object-in-the-objects-panel.png)

### Optional: Add the LensDistortion component

> Use this section only if the LensDistortion component is not already listed in the Properties panel. If it is already present, skip the actions in this section and continue with the main tutorial below.


2.1. Tap Add Component to add LensDistortion.

![Tap Add Component to add LensDistortion.](/img/guides/lens-distortion/02_tap-add-component-to-add-lensdistortion.png)

2.2. Open the Render category.

![Open the Render category.](/img/guides/lens-distortion/03_open-the-render-category.png)

2.3. Open the Lens category.

![Open the Lens category.](/img/guides/lens-distortion/04_open-the-lens-category.png)

2.4. Select the LensDistortion component.

![Select the LensDistortion component.](/img/guides/lens-distortion/05_select-the-lensdistortion-component.png)

**End of optional section. Continue with the main tutorial below.**

2. Select the LensDistortion component to view its settings.

![Select the LensDistortion component to view its settings.](/img/guides/lens-distortion/06_select-the-lensdistortion-component-to-view-its-settings.png)

Lens Distortion bends the image like a curved camera lens.

- **Distortion:** Bends the image inward or outward.
- **Scale:** Keeps the image framed after bending.

3. LensDistortion settings are visible in Properties.

![LensDistortion settings are visible in Properties.](/img/guides/lens-distortion/07_lensdistortion-settings-are-visible-in-properties.png)

## Result

The LensDistortion component is now configured and its settings are visible in the Properties panel. You can adjust its values and preview the result in your scene.
