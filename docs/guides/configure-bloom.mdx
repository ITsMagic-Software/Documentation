# Configuring Bloom

Bloom creates a soft glow around very bright parts of the image.

Strength controls glow. Threshold chooses bright pixels. Blur size and levels control spread. Quality balances appearance and performance.

## Steps

1. Select the POST PROCESSING object in the Objects panel.

![Select the POST PROCESSING object in the Objects panel.](/img/guides/configure-bloom/01_select-the-post-processing-object-in-the-objects-panel.png)

### Optional: Add the Bloom component

> Use this section only if the Bloom component is not already listed in the Properties panel. If it is already present, skip the actions in this section and continue with the main tutorial below.


**End of optional section. Continue with the main tutorial below.**

2. Select the Bloom component to view its settings.

![Select the Bloom component to view its settings.](/img/guides/configure-bloom/02_select-the-bloom-component-to-view-its-settings.png)

Bloom makes bright parts of the image glow.

- **Strength:** How strong the glow is.
- **Threshold:** How bright a pixel must be before it glows.
- **Blur size and levels:** How far and smoothly the glow spreads.
- **Quality:** The balance between smoothness and performance.
- **Highlight, ghost, and halo controls:** Additional streaks and reflections around bright areas.

3. Bloom settings are visible in the Properties panel.

![Bloom settings are visible in the Properties panel.](/img/guides/configure-bloom/03_bloom-settings-are-visible-in-the-properties-panel.png)

## Result

The Bloom component is now configured and its settings are visible in the Properties panel. You can adjust its values and preview the result in your scene.
