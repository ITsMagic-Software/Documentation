# Configuring Contact Shadows

Contact Shadows add short shadows where nearby surfaces meet, helping objects feel grounded.

Intensity controls darkness. Shadow and contact distance limit reach. Bias prevents artifacts. Samples and rays improve quality.

## Steps

1. Select the POST PROCESSING object in the Objects panel.

![Select the POST PROCESSING object in the Objects panel.](/img/guides/configure-contact-shadows/01_select-the-post-processing-object-in-the-objects-panel.png)

### Optional: Add the ContactShadows component

> Use this section only if the ContactShadows component is not already listed in the Properties panel. If it is already present, skip the actions in this section and continue with the main tutorial below.


2.1. Tap Add Component to add Contact Shadows.

![Tap Add Component to add Contact Shadows.](/img/guides/configure-contact-shadows/02_tap-add-component-to-add-contact-shadows.png)

2.2. Open the Render category.

![Open the Render category.](/img/guides/configure-contact-shadows/03_open-the-render-category.png)

2.3. Open the Lighting category.

![Open the Lighting category.](/img/guides/configure-contact-shadows/04_open-the-lighting-category.png)

2.4. Select the Contact Shadows component.

![Select the Contact Shadows component.](/img/guides/configure-contact-shadows/05_select-the-contact-shadows-component.png)

**End of optional section. Continue with the main tutorial below.**

2. Select the Contact Shadows component to view its settings.

![Select the Contact Shadows component to view its settings.](/img/guides/configure-contact-shadows/06_select-the-contact-shadows-component-to-view-its-settings.png)

Contact Shadows ground objects where nearby surfaces meet.

- **Intensity:** Darkness of the contact shadow.
- **Light cone and shadow distance:** The area where shadows can be projected.
- **Contact distance:** How far nearby geometry can contribute.
- **Depth bias and slope bias:** Reduce unwanted shadow marks.
- **Sample count and ray count:** Improve quality with extra processing.

3. Contact Shadows settings are visible in Properties.

![Contact Shadows settings are visible in Properties.](/img/guides/configure-contact-shadows/07_contact-shadows-settings-are-visible-in-properties.png)

## Result

The Contact Shadows component is now configured and its settings are visible in the Properties panel. You can adjust its values and preview the result in your scene.
