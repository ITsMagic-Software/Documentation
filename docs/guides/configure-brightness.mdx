# Configuring Brightness

Brightness adjusts the overall light level of the rendered image.

Brightness makes the image lighter or darker.

## Steps

1. Select the POST PROCESSING object in the Objects panel.

![Select the POST PROCESSING object in the Objects panel.](/img/guides/configure-brightness/01_select-the-post-processing-object-in-the-objects-panel.png)

### Optional: Add the Brightness component

> Use this section only if the Brightness component is not already listed in the Properties panel. If it is already present, skip the actions in this section and continue with the main tutorial below.


2.1. Tap Add Component to add Brightness.

![Tap Add Component to add Brightness.](/img/guides/configure-brightness/02_tap-add-component-to-add-brightness.png)

2.2. Open the Render category.

![Open the Render category.](/img/guides/configure-brightness/03_open-the-render-category.png)

2.3. Open the Color grading category.

![Open the Color grading category.](/img/guides/configure-brightness/04_open-the-color-grading-category.png)

2.4. Select the Brightness component.

![Select the Brightness component.](/img/guides/configure-brightness/05_select-the-brightness-component.png)

**End of optional section. Continue with the main tutorial below.**

2. Select the Brightness component to view its settings.

![Select the Brightness component to view its settings.](/img/guides/configure-brightness/06_select-the-brightness-component-to-view-its-settings.png)

Brightness changes the overall light level.

- **Brightness:** Makes the complete image lighter or darker.

3. Brightness settings are visible in the Properties panel.

![Brightness settings are visible in the Properties panel.](/img/guides/configure-brightness/07_brightness-settings-are-visible-in-the-properties-panel.png)

## Result

The Brightness component is now configured and its settings are visible in the Properties panel. You can adjust its values and preview the result in your scene.
