# Configuring SSAO

SSAO darkens small creases and corners where surfaces block ambient light.

Radius controls contributing geometry. Intensity controls corner darkness. Bias and samples reduce artifacts.

## Steps

1. Select the POST PROCESSING object in the Objects panel.

![Select the POST PROCESSING object in the Objects panel.](/img/guides/ssao/01_select-the-post-processing-object-in-the-objects-panel.png)

### Optional: Add the SSAO component

> Use this section only if the SSAO component is not already listed in the Properties panel. If it is already present, skip the actions in this section and continue with the main tutorial below.


**End of optional section. Continue with the main tutorial below.**

2. Select the SSAO component to view its settings.

![Select the SSAO component to view its settings.](/img/guides/ssao/02_select-the-ssao-component-to-view-its-settings.png)

SSAO darkens creases and corners where surfaces block ambient light.

- **Radius:** How far geometry contributes.
- **Intensity:** Occlusion darkness.
- **Bias:** Reduces surface artifacts.
- **Samples:** Improves quality.

3. SSAO settings are visible in Properties.

![SSAO settings are visible in Properties.](/img/guides/ssao/03_ssao-settings-are-visible-in-properties.png)

## Result

The SSAO component is now configured and its settings are visible in the Properties panel. You can adjust its values and preview the result in your scene.
