# Configuring VHSFilter

VHS Filter imitates old videotape noise, scanlines, and tracking instability.

Noise adds grain. Tracking and distortion recreate tape movement. Scanlines and color shift shape the look. Speed controls movement.

## Steps

1. Select the POST PROCESSING object in the Objects panel.

![Select the POST PROCESSING object in the Objects panel.](/img/guides/vhs-filter/01_select-the-post-processing-object-in-the-objects-panel.png)

### Optional: Add the VHSFilter component

> Use this section only if the VHSFilter component is not already listed in the Properties panel. If it is already present, skip the actions in this section and continue with the main tutorial below.


2.1. Tap Add Component to add VHSFilter.

![Tap Add Component to add VHSFilter.](/img/guides/vhs-filter/02_tap-add-component-to-add-vhsfilter.png)

2.2. Open the Render category.

![Open the Render category.](/img/guides/vhs-filter/03_open-the-render-category.png)

2.3. Open the Film category.

![Open the Film category.](/img/guides/vhs-filter/04_open-the-film-category.png)

2.4. Select the VHSFilter component.

![Select the VHSFilter component.](/img/guides/vhs-filter/05_select-the-vhsfilter-component.png)

**End of optional section. Continue with the main tutorial below.**

2. Select the VHSFilter component to view its settings.

![Select the VHSFilter component to view its settings.](/img/guides/vhs-filter/06_select-the-vhsfilter-component-to-view-its-settings.png)

VHS Filter imitates old videotape artifacts.

- **Noise:** Analog grain.
- **Tracking and distortion:** Tape instability.
- **Scanlines and color shift:** VHS appearance.
- **Speed:** Artifact movement.

3. VHSFilter settings are visible in Properties.

![VHSFilter settings are visible in Properties.](/img/guides/vhs-filter/07_vhsfilter-settings-are-visible-in-properties.png)

## Result

The VHSFilter component is now configured and its settings are visible in the Properties panel. You can adjust its values and preview the result in your scene.
