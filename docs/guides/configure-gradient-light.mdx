# Configuring GradientLight

Gradient Light adds a directional light tint that transitions between colors.

Top and bottom colors define the gradient. Intensity controls brightness. Direction and rotation aim it.

## Steps

1. Select the POST PROCESSING object in the Objects panel.

![Select the POST PROCESSING object in the Objects panel.](/img/guides/configure-gradient-light/01_select-the-post-processing-object-in-the-objects-panel.png)

### Optional: Add the GradientLight component

> Use this section only if the GradientLight component is not already listed in the Properties panel. If it is already present, skip the actions in this section and continue with the main tutorial below.


2.1. Tap Add Component to add GradientLight.

![Tap Add Component to add GradientLight.](/img/guides/configure-gradient-light/02_tap-add-component-to-add-gradientlight.png)

2.2. Open the Render category.

![Open the Render category.](/img/guides/configure-gradient-light/03_open-the-render-category.png)

2.3. Open the Light category.

![Open the Light category.](/img/guides/configure-gradient-light/04_open-the-light-category.png)

2.4. Select the GradientLight component.

![Select the GradientLight component.](/img/guides/configure-gradient-light/05_select-the-gradientlight-component.png)

**End of optional section. Continue with the main tutorial below.**

2. Select the GradientLight component to view its settings.

![Select the GradientLight component to view its settings.](/img/guides/configure-gradient-light/06_select-the-gradientlight-component-to-view-its-settings.png)

Gradient Light adds a smoothly changing directional light tint.

- **Top and bottom colors:** The colors at each end of the gradient.
- **Intensity:** Gradient brightness.
- **Direction and rotation:** How the gradient is aimed.

3. GradientLight settings are visible in Properties.

![GradientLight settings are visible in Properties.](/img/guides/configure-gradient-light/07_gradientlight-settings-are-visible-in-properties.png)

## Result

The GradientLight component is now configured and its settings are visible in the Properties panel. You can adjust its values and preview the result in your scene.
