# Configuring ToneMapper

Tone Mapper converts high-dynamic-range lighting into a display-friendly image.

Exposure changes brightness. Contrast and saturation shape the look. Operator selects the mapping style. White point defines white.

## Steps

1. Select the POST PROCESSING object in the Objects panel.

![Select the POST PROCESSING object in the Objects panel.](/img/guides/tone-mapper/01_select-the-post-processing-object-in-the-objects-panel.png)

### Optional: Add the ToneMapper component

> Use this section only if the ToneMapper component is not already listed in the Properties panel. If it is already present, skip the actions in this section and continue with the main tutorial below.


**End of optional section. Continue with the main tutorial below.**

2. Select the ToneMapper component to view its settings.

![Select the ToneMapper component to view its settings.](/img/guides/tone-mapper/02_select-the-tonemapper-component-to-view-its-settings.png)

Tone Mapper adapts high-dynamic-range lighting for the display.

- **Exposure:** Overall brightness.
- **Contrast and saturation:** General tone and color.
- **Operator:** Tone-mapping style.
- **White point:** What should appear white.

3. ToneMapper settings are visible in Properties.

![ToneMapper settings are visible in Properties.](/img/guides/tone-mapper/03_tonemapper-settings-are-visible-in-properties.png)

## Result

The ToneMapper component is now configured and its settings are visible in the Properties panel. You can adjust its values and preview the result in your scene.
