# Configuring Sharpen

Sharpen increases edge definition so the image appears crisper.

Strength controls edge sharpening. Clamp and contrast limits prevent halos.

## Steps

1. Select the POST PROCESSING object in the Objects panel.

![Select the POST PROCESSING object in the Objects panel.](/img/guides/sharpen/01_select-the-post-processing-object-in-the-objects-panel.png)

### Optional: Add the Sharpen component

> Use this section only if the Sharpen component is not already listed in the Properties panel. If it is already present, skip the actions in this section and continue with the main tutorial below.


2.1. Tap Add Component to add Sharpen.

![Tap Add Component to add Sharpen.](/img/guides/sharpen/02_tap-add-component-to-add-sharpen.png)

2.2. Open the Render category.

![Open the Render category.](/img/guides/sharpen/03_open-the-render-category.png)

2.3. Open the Highlights category.

![Open the Highlights category.](/img/guides/sharpen/04_open-the-highlights-category.png)

2.4. Select the Sharpen component.

![Select the Sharpen component.](/img/guides/sharpen/05_select-the-sharpen-component.png)

**End of optional section. Continue with the main tutorial below.**

2. Select the Sharpen component to view its settings.

![Select the Sharpen component to view its settings.](/img/guides/sharpen/06_select-the-sharpen-component-to-view-its-settings.png)

Sharpen makes edges appear crisper.

- **Strength:** Sharpening amount.
- **Clamp and contrast limit:** Prevent bright halos and excessive sharpening.

3. Sharpen settings are visible in Properties.

![Sharpen settings are visible in Properties.](/img/guides/sharpen/07_sharpen-settings-are-visible-in-properties.png)

## Result

The Sharpen component is now configured and its settings are visible in the Properties panel. You can adjust its values and preview the result in your scene.
