# Configuring a scene skybox

A Skybox is the environment surrounding the scene. It provides the background image or color visible beyond the scene geometry and helps establish the scene's lighting and atmosphere.

## Steps

1. Select the POST PROCESSING object in the Objects panel.

![Select the POST PROCESSING object in the Objects panel.](/img/guides/configure-skybox/01_select-the-post-processing-object-in-the-objects-panel.png)

### Optional: Add the Skybox component

> Use this section only if the Skybox component is not already listed in the Properties panel. If it is already present, skip the actions in this section and continue with the main tutorial below.


2.1. Tap Add Component to begin adding Skybox.

![Tap Add Component to begin adding Skybox.](/img/guides/configure-skybox/02_tap-add-component-to-begin-adding-skybox.png)

2.2. Open the Render category.

![Open the Render category.](/img/guides/configure-skybox/03_open-the-render-category.png)

2.3. Open the Skybox category.

![Open the Skybox category.](/img/guides/configure-skybox/04_open-the-skybox-category.png)

2.4. Select the Skybox component.

![Select the Skybox component.](/img/guides/configure-skybox/05_select-the-skybox-component.png)

**End of optional section. Continue with the main tutorial below.**

2. Select the Skybox component to view its settings.

![Select the Skybox component to view its settings.](/img/guides/configure-skybox/06_select-the-skybox-component-to-view-its-settings.png)

The Skybox component controls the scene background environment.

- **Color:** Changes the sky color.
- **Lux:** Controls only the brightness of the sky.
- **Skybox:** Selects the cubemap texture used as the environment.
- **Resolution:** Controls the cubemap resolution.
- **Show sun:** Displays a representation of the sun in the skybox.

3. Skybox settings are visible in the Properties panel.

![Skybox settings are visible in the Properties panel.](/img/guides/configure-skybox/07_skybox-settings-are-visible-in-the-properties-panel.png)

## Result

The a scene skybox component is now configured and its settings are visible in the Properties panel. You can adjust its values and preview the result in your scene.
