# Configuring FilmGrainScratch

Film Grain/Scratch gives the image an old-film appearance.

Grain amount adds noise. Scratch amount and size control scratches. Colored grain adds variation. Speed controls movement.

## Steps

1. Select the POST PROCESSING object in the Objects panel.

![Select the POST PROCESSING object in the Objects panel.](/img/guides/configure-film-grain-scratch/01_select-the-post-processing-object-in-the-objects-panel.png)

### Optional: Add the FilmGrainScratch component

> Use this section only if the FilmGrainScratch component is not already listed in the Properties panel. If it is already present, skip the actions in this section and continue with the main tutorial below.


2.1. Tap Add Component to add FilmGrainScratch.

![Tap Add Component to add FilmGrainScratch.](/img/guides/configure-film-grain-scratch/02_tap-add-component-to-add-filmgrainscratch.png)

2.2. Open the Render category.

![Open the Render category.](/img/guides/configure-film-grain-scratch/03_open-the-render-category.png)

2.3. Open the Film category.

![Open the Film category.](/img/guides/configure-film-grain-scratch/04_open-the-film-category.png)

2.4. Select the FilmGrainScratch component.

![Select the FilmGrainScratch component.](/img/guides/configure-film-grain-scratch/05_select-the-filmgrainscratch-component.png)

**End of optional section. Continue with the main tutorial below.**

2. Select the FilmGrainScratch component to view its settings.

![Select the FilmGrainScratch component to view its settings.](/img/guides/configure-film-grain-scratch/06_select-the-filmgrainscratch-component-to-view-its-settings.png)

Film Grain/Scratch gives the image an old-film appearance.

- **Grain amount:** Fine film noise.
- **Scratch amount and size:** Number and size of scratches.
- **Colored grain:** Whether the grain has color variation.
- **Speed:** How quickly the pattern changes.

3. FilmGrainScratch settings are visible in Properties.

![FilmGrainScratch settings are visible in Properties.](/img/guides/configure-film-grain-scratch/07_filmgrainscratch-settings-are-visible-in-properties.png)

## Result

The FilmGrainScratch component is now configured and its settings are visible in the Properties panel. You can adjust its values and preview the result in your scene.
