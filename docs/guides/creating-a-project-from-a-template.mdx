# Creating a Project from a Template

Templates give you a ready-made starting point. In this guide, you will create a project from the **Double hitch pickup** template. You can change its assets and setup after the project is created.

## Steps

### 1. Open the project menu

Tap **New project** on the ITsMagic home screen.

![Tap New project.](/img/guides/create-double-hitch-pickup-project/01_tap-new-project.png)

### 2. Select the template

Find and select **Double hitch pickup** from the list of templates. Selecting it opens the template as the starting point for your project.

![Select the Double hitch pickup template.](/img/guides/create-double-hitch-pickup-project/02_select-the-double-hitch-pickup-template.png)

### 3. Start from the template

Tap **Create project** to use the selected template.

![Tap Create project.](/img/guides/create-double-hitch-pickup-project/03_tap-create-project-to-use-this-template-as-your-starting-point.png)

### 4. Name your project

Enter a short, recognizable name in **Project title**. Use a name that describes your own project, rather than relying on the template name.

![Choose a project name.](/img/guides/create-double-hitch-pickup-project/04_choose-a-clear-name-for-your-project-so-you-can-find-it-easily-later.png)

### 5. Create the project

Tap **Confirm**. ITsMagic will create your project with the template's initial assets and setup.

![Tap Confirm.](/img/guides/create-double-hitch-pickup-project/05_tap-confirm-to-create-your-project-from-the-template.png)

You can now explore the template, replace its content, and adapt it to your own game.
