# Creating a Project from a Template

Templates give you a ready-made starting point. In this guide, the **Double hitch pickup** template is used as an example, but you can choose any template you prefer. You can change the template's assets and setup after the project is created.

## Steps

### 1. Open the project menu

Tap **New project** on the ITsMagic home screen.

![Tap New project.](/img/guides/create-double-hitch-pickup-project/01_tap-new-project.png)

### 2. Select a template

Select any template you would like to use. This demonstration uses **Double hitch pickup** as an example.

![Select a template.](/img/guides/create-double-hitch-pickup-project/02_select-any-template-you-would-like-to-use-this-demonstration-uses-double-hitch-pickup.png)

### 3. Start from the template

Tap **Create project** to use the selected template.

![Tap Create project.](/img/guides/create-double-hitch-pickup-project/03_tap-create-project-to-use-this-template-as-your-starting-point.png)

### 4. Name your project

Enter a short, recognizable name in **Project title**. Use a name that describes your own project, rather than relying on the template name.

![Choose a project name.](/img/guides/create-double-hitch-pickup-project/04_choose-a-clear-name-for-your-project-so-you-can-find-it-easily-later.png)

### 5. Create the project

Tap **Confirm**. ITsMagic will create your project with the template's initial assets and setup.

![Tap Confirm.](/img/guides/create-double-hitch-pickup-project/05_tap-confirm-to-create-your-project-from-the-template.png)

### 6. Wait while the project opens

ITsMagic now opens and builds the project. Wait for the opening screen to finish before continuing.

![Wait while the project opens and is built.](/img/guides/create-double-hitch-pickup-project/06_the-project-is-opening-and-being-built-please-wait-for-this-opening-screen-to-finish.png)

### 7. Start working in the editor

When the new project finishes loading, it opens in the editor. You can now explore the template, replace its content, and adapt it to your own game.

![The new project is open in the editor.](/img/guides/create-double-hitch-pickup-project/07_the-new-project-has-finished-loading-and-is-open-in-the-editor.png)
