# Configuring CavityRidgeValley

Cavity Ridge/Valley enhances raised and recessed surface details.

Ridge strength emphasizes raised details. Valley strength emphasizes recessed details. Distance and power control reach and intensity.

## Steps

1. Select the POST PROCESSING object in the Objects panel.

![Select the POST PROCESSING object in the Objects panel.](/img/guides/configure-cavity-ridge-valley/01_select-the-post-processing-object-in-the-objects-panel.png)

### Optional: Add the CavityRidgeValley component

> Use this section only if the CavityRidgeValley component is not already listed in the Properties panel. If it is already present, skip the actions in this section and continue with the main tutorial below.


2.1. Tap Add Component to add CavityRidgeValley.

![Tap Add Component to add CavityRidgeValley.](/img/guides/configure-cavity-ridge-valley/02_tap-add-component-to-add-cavityridgevalley.png)

2.2. Open the Render category.

![Open the Render category.](/img/guides/configure-cavity-ridge-valley/03_open-the-render-category.png)

2.3. Open the Highlights category.

![Open the Highlights category.](/img/guides/configure-cavity-ridge-valley/04_open-the-highlights-category.png)

2.4. Select the CavityRidgeValley component.

![Select the CavityRidgeValley component.](/img/guides/configure-cavity-ridge-valley/05_select-the-cavityridgevalley-component.png)

**End of optional section. Continue with the main tutorial below.**

2. Select the Cavity Ridge/Valley component to view its settings.

![Select the Cavity Ridge/Valley component to view its settings.](/img/guides/configure-cavity-ridge-valley/06_select-the-cavity-ridge-valley-component-to-view-its-settings.png)

Cavity Ridge/Valley makes small surface details easier to see.

- **Ridge strength:** Emphasizes raised details.
- **Valley strength:** Emphasizes recessed details.
- **Distance:** How far the detail effect reaches.
- **Power:** The intensity of the detail contrast.

3. Cavity Ridge/Valley settings are visible in the Properties panel.

![Cavity Ridge/Valley settings are visible in the Properties panel.](/img/guides/configure-cavity-ridge-valley/07_cavity-ridge-valley-settings-are-visible-in-the-properties-panel.png)

## Result

The CavityRidgeValley component is now configured and its settings are visible in the Properties panel. You can adjust its values and preview the result in your scene.
