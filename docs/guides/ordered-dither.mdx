# Configuring OrderedDither

Ordered Dither creates a retro limited-palette pattern.

Color levels set shades. Pattern size controls the pattern. Strength blends it with the original.

## Steps

1. Select the POST PROCESSING object in the Objects panel.

![Select the POST PROCESSING object in the Objects panel.](/img/guides/ordered-dither/01_select-the-post-processing-object-in-the-objects-panel.png)

### Optional: Add the OrderedDither component

> Use this section only if the OrderedDither component is not already listed in the Properties panel. If it is already present, skip the actions in this section and continue with the main tutorial below.


2.1. Tap Add Component to add OrderedDither.

![Tap Add Component to add OrderedDither.](/img/guides/ordered-dither/02_tap-add-component-to-add-ordereddither.png)

2.2. Open the Render category.

![Open the Render category.](/img/guides/ordered-dither/03_open-the-render-category.png)

2.3. Open the Stylized category.

![Open the Stylized category.](/img/guides/ordered-dither/04_open-the-stylized-category.png)

2.4. Select the OrderedDither component.

![Select the OrderedDither component.](/img/guides/ordered-dither/05_select-the-ordereddither-component.png)

**End of optional section. Continue with the main tutorial below.**

2. Select the OrderedDither component to view its settings.

![Select the OrderedDither component to view its settings.](/img/guides/ordered-dither/06_select-the-ordereddither-component-to-view-its-settings.png)

Ordered Dither creates a retro limited-palette pattern.

- **Color levels:** Number of shades retained.
- **Pattern size:** Size of the repeating pattern.
- **Strength:** Blend with the original image.

3. OrderedDither settings are visible in Properties.

![OrderedDither settings are visible in Properties.](/img/guides/ordered-dither/07_ordereddither-settings-are-visible-in-properties.png)

## Result

The OrderedDither component is now configured and its settings are visible in the Properties panel. You can adjust its values and preview the result in your scene.
