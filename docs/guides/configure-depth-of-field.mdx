# Configuring DepthOfField

Depth of Field keeps one distance sharp while blurring nearer and farther areas.

Focus distance chooses what is sharp. Aperture controls blur around it. Scale changes strength. Quality and resolution balance performance.

## Steps

1. Select the POST PROCESSING object in the Objects panel.

![Select the POST PROCESSING object in the Objects panel.](/img/guides/configure-depth-of-field/01_select-the-post-processing-object-in-the-objects-panel.png)

### Optional: Add the DepthOfField component

> Use this section only if the DepthOfField component is not already listed in the Properties panel. If it is already present, skip the actions in this section and continue with the main tutorial below.


2.1. Tap Add Component to add DepthOfField.

![Tap Add Component to add DepthOfField.](/img/guides/configure-depth-of-field/02_tap-add-component-to-add-depthoffield.png)

2.2. Open the Render category.

![Open the Render category.](/img/guides/configure-depth-of-field/03_open-the-render-category.png)

2.3. Open the Lens category.

![Open the Lens category.](/img/guides/configure-depth-of-field/04_open-the-lens-category.png)

2.4. Select the DepthOfField component.

![Select the DepthOfField component.](/img/guides/configure-depth-of-field/05_select-the-depthoffield-component.png)

**End of optional section. Continue with the main tutorial below.**

2. Select the DepthOfField component to view its settings.

![Select the DepthOfField component to view its settings.](/img/guides/configure-depth-of-field/06_select-the-depthoffield-component-to-view-its-settings.png)

Depth of Field simulates a camera focus.

- **Focus distance:** The distance that stays sharp.
- **Aperture:** How much nearby and distant areas blur.
- **Scale:** Overall blur strength.
- **Quality and resolution:** Smoothness and performance of the effect.

3. DepthOfField settings are visible in Properties.

![DepthOfField settings are visible in Properties.](/img/guides/configure-depth-of-field/07_depthoffield-settings-are-visible-in-properties.png)

## Result

The DepthOfField component is now configured and its settings are visible in the Properties panel. You can adjust its values and preview the result in your scene.
