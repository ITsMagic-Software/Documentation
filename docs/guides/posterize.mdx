# Configuring Posterize

Posterize simplifies the image into a small number of flat color bands.

Levels control remaining tones. Dither can soften transitions.

## Steps

1. Select the POST PROCESSING object in the Objects panel.

![Select the POST PROCESSING object in the Objects panel.](/img/guides/posterize/01_select-the-post-processing-object-in-the-objects-panel.png)

### Optional: Add the Posterize component

> Use this section only if the Posterize component is not already listed in the Properties panel. If it is already present, skip the actions in this section and continue with the main tutorial below.


2.1. Tap Add Component to add Posterize.

![Tap Add Component to add Posterize.](/img/guides/posterize/02_tap-add-component-to-add-posterize.png)

2.2. Open the Render category.

![Open the Render category.](/img/guides/posterize/03_open-the-render-category.png)

2.3. Open the Stylized category.

![Open the Stylized category.](/img/guides/posterize/04_open-the-stylized-category.png)

2.4. Select the Posterize component.

![Select the Posterize component.](/img/guides/posterize/05_select-the-posterize-component.png)

**End of optional section. Continue with the main tutorial below.**

2. Select the Posterize component to view its settings.

![Select the Posterize component to view its settings.](/img/guides/posterize/06_select-the-posterize-component-to-view-its-settings.png)

Posterize reduces the image to flat color bands.

- **Levels:** Number of tones kept.
- **Dither:** Softens transitions between bands.

3. Posterize settings are visible in Properties.

![Posterize settings are visible in Properties.](/img/guides/posterize/07_posterize-settings-are-visible-in-properties.png)

## Result

The Posterize component is now configured and its settings are visible in the Properties panel. You can adjust its values and preview the result in your scene.
