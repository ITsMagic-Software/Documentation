# Configuring Contrast/Brightness/Saturation

These controls adjust brightness, contrast, and color intensity together.

Brightness changes light level. Contrast changes light/dark difference. Saturation makes colors vivid or gray.

## Steps

1. Select the POST PROCESSING object in the Objects panel.

![Select the POST PROCESSING object in the Objects panel.](/img/guides/configure-contrast-brightness-saturation/01_select-the-post-processing-object-in-the-objects-panel.png)

### Optional: Add the ContrastBrightnessSaturation component

> Use this section only if the ContrastBrightnessSaturation component is not already listed in the Properties panel. If it is already present, skip the actions in this section and continue with the main tutorial below.


2.1. Tap Add Component to add Contrast/Brightness/Saturation.

![Tap Add Component to add Contrast/Brightness/Saturation.](/img/guides/configure-contrast-brightness-saturation/02_tap-add-component-to-add-contrast-brightness-saturation.png)

2.2. Open the Render category.

![Open the Render category.](/img/guides/configure-contrast-brightness-saturation/03_open-the-render-category.png)

2.3. Open the Color grading category.

![Open the Color grading category.](/img/guides/configure-contrast-brightness-saturation/04_open-the-color-grading-category.png)

2.4. Select the Contrast/Brightness/Saturation component.

![Select the Contrast/Brightness/Saturation component.](/img/guides/configure-contrast-brightness-saturation/05_select-the-contrast-brightness-saturation-component.png)

**End of optional section. Continue with the main tutorial below.**

2. Select the Contrast/Brightness/Saturation component to view its settings.

![Select the Contrast/Brightness/Saturation component to view its settings.](/img/guides/configure-contrast-brightness-saturation/06_select-the-contrast-brightness-saturation-component-to-view-its-settings.png)

These three controls adjust the general color and tone.

- **Brightness:** Makes the image lighter or darker.
- **Contrast:** Changes the difference between light and dark.
- **Saturation:** Makes colors vivid or moves them toward gray.

3. Contrast/Brightness/Saturation settings are visible in Properties.

![Contrast/Brightness/Saturation settings are visible in Properties.](/img/guides/configure-contrast-brightness-saturation/07_contrast-brightness-saturation-settings-are-visible-in-properties.png)

## Result

The Contrast/Brightness/Saturation component is now configured and its settings are visible in the Properties panel. You can adjust its values and preview the result in your scene.
