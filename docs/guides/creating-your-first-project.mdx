# Creating Your First Project

This guide shows you how to create a blank project in ITsMagic. A blank project is a good starting point when you want to build everything yourself.

## Steps

### 1. Open the project menu

Tap **New project** on the ITsMagic home screen.

![Tap New project.](/img/guides/create-empty-project/01_tap-new-project.png)

### 2. Choose an empty project

At the top of the template selection screen, tap **New empty project**. This option creates a project without a preconfigured template.

![Tap New empty project.](/img/guides/create-empty-project/02_tap-new-empty-project-at-the-top-of-the-template-selection-screen.png)

### 3. Name your project

Enter a short, recognizable name in **Project title**. Choose a name that will help you find the project easily later.

![Choose a project name.](/img/guides/create-empty-project/03_choose-a-clear-name-for-your-project-so-you-can-find-it-easily-later.png)

### 4. Create the project

Tap **Confirm**. ITsMagic will create your blank project and open it in the editor.

![Tap Confirm.](/img/guides/create-empty-project/04_tap-confirm-to-create-the-project.png)

### 5. Wait while the project opens

ITsMagic now opens and builds the project. Wait for the opening screen to finish before continuing.

![Wait while the project opens and is built.](/img/guides/create-empty-project/05_the-project-is-opening-and-being-built-please-wait-for-this-opening-screen-to-finish.png)

### 6. Start working in the editor

When the new empty project finishes loading, it opens in the editor. You can now start adding scenes, objects, components, and scripts to your project.

![The new empty project is open in the editor.](/img/guides/create-empty-project/06_the-new-empty-project-has-finished-loading-and-is-open-in-the-editor.png)
