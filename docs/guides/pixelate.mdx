# Configuring Pixelate

Pixelate groups the image into large blocks for a low-resolution style.

Pixel size controls block size. Aspect and resolution keep the pattern aligned.

## Steps

1. Select the POST PROCESSING object in the Objects panel.

![Select the POST PROCESSING object in the Objects panel.](/img/guides/pixelate/01_select-the-post-processing-object-in-the-objects-panel.png)

### Optional: Add the Pixelate component

> Use this section only if the Pixelate component is not already listed in the Properties panel. If it is already present, skip the actions in this section and continue with the main tutorial below.


2.1. Tap Add Component to add Pixelate.

![Tap Add Component to add Pixelate.](/img/guides/pixelate/02_tap-add-component-to-add-pixelate.png)

2.2. Open the Render category.

![Open the Render category.](/img/guides/pixelate/03_open-the-render-category.png)

2.3. Open the Stylized category.

![Open the Stylized category.](/img/guides/pixelate/04_open-the-stylized-category.png)

2.4. Select the Pixelate component.

![Select the Pixelate component.](/img/guides/pixelate/05_select-the-pixelate-component.png)

**End of optional section. Continue with the main tutorial below.**

2. Select the Pixelate component to view its settings.

![Select the Pixelate component to view its settings.](/img/guides/pixelate/06_select-the-pixelate-component-to-view-its-settings.png)

Pixelate groups the image into large blocks.

- **Pixel size:** Block size.
- **Aspect and resolution:** Keep the pattern aligned with the screen.

3. Pixelate settings are visible in Properties.

![Pixelate settings are visible in Properties.](/img/guides/pixelate/07_pixelate-settings-are-visible-in-properties.png)

## Result

The Pixelate component is now configured and its settings are visible in the Properties panel. You can adjust its values and preview the result in your scene.
