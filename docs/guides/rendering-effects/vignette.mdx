# Configuring Vignette

Vignette darkens or colors the image corners to focus attention on the center.

Color tints corners. Intensity controls darkness. Radius and softness set where it starts and fades.

## Steps

1. Select the POST PROCESSING object in the Objects panel.

![Select the POST PROCESSING object in the Objects panel.](/img/guides/vignette/01_select-the-post-processing-object-in-the-objects-panel.png)

### Optional: Add the Vignette component

> Use this section only if the Vignette component is not already listed in the Properties panel. If it is already present, skip the actions in this section and continue with the main tutorial below.


**End of optional section. Continue with the main tutorial below.**

2. Select the Vignette component to view its settings.

![Select the Vignette component to view its settings.](/img/guides/vignette/02_select-the-vignette-component-to-view-its-settings.png)

Vignette focuses attention toward the center of the image.

- **Color:** Corner tint.
- **Intensity:** Corner darkness.
- **Radius:** Where the effect begins.
- **Softness:** How smoothly it fades.

3. Vignette settings are visible in Properties.

![Vignette settings are visible in Properties.](/img/guides/vignette/03_vignette-settings-are-visible-in-properties.png)

## Result

The Vignette component is now configured and its settings are visible in the Properties panel. You can adjust its values and preview the result in your scene.
