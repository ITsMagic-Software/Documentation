# Configuring AtmosphericScattering

Atmospheric scattering creates a sky and distant haze that resemble a real atmosphere.

Sky and sun colors set the palette. Sun direction and intensity position and brighten the sun. Rayleigh, Mie, clouds, and density shape the atmosphere. Resolution controls quality.

## Steps

1. Select the POST PROCESSING object in the Objects panel.

![Select the POST PROCESSING object in the Objects panel.](/img/guides/configure-atmospheric-scattering/01_select-the-post-processing-object-in-the-objects-panel.png)

### Optional: Add the AtmosphericScattering component

> Use this section only if the AtmosphericScattering component is not already listed in the Properties panel. If it is already present, skip the actions in this section and continue with the main tutorial below.


2.1. Tap Add Component to add AtmosphericScattering.

![Tap Add Component to add AtmosphericScattering.](/img/guides/configure-atmospheric-scattering/02_tap-add-component-to-add-atmosphericscattering.png)

2.2. Open the Render category.

![Open the Render category.](/img/guides/configure-atmospheric-scattering/03_open-the-render-category.png)

2.3. Open the Skybox category.

![Open the Skybox category.](/img/guides/configure-atmospheric-scattering/04_open-the-skybox-category.png)

2.4. Select the AtmosphericScattering component.

![Select the AtmosphericScattering component.](/img/guides/configure-atmospheric-scattering/05_select-the-atmosphericscattering-component.png)

**End of optional section. Continue with the main tutorial below.**

2. Select the AtmosphericScattering component to view its settings.

![Select the AtmosphericScattering component to view its settings.](/img/guides/configure-atmospheric-scattering/06_select-the-atmosphericscattering-component-to-view-its-settings.png)

The Atmospheric Scattering controls build the sky and distant haze.

- **Sky and sun colors:** The colors of the atmosphere and sunlight.
- **Sun direction and intensity:** Where the sun is and how bright it is.
- **Rayleigh and Mie settings:** The blue sky and warm haze around the sun.
- **Clouds and density:** Cloud coverage and atmospheric thickness.
- **Resolution:** The quality of the atmosphere calculation.

3. AtmosphericScattering settings are visible in the Properties panel.

![AtmosphericScattering settings are visible in the Properties panel.](/img/guides/configure-atmospheric-scattering/07_atmosphericscattering-settings-are-visible-in-the-properties-panel.png)

## Result

The AtmosphericScattering component is now configured and its settings are visible in the Properties panel. You can adjust its values and preview the result in your scene.
