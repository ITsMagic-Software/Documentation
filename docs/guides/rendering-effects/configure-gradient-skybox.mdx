# Configuring GradientSkybox

Gradient Skybox creates a simple colored sky from horizon to zenith.

Top and bottom colors define the sky. Sun color, size, and position customize the sun. Brightness and resolution control visibility and quality.

## Steps

1. Select the POST PROCESSING object in the Objects panel.

![Select the POST PROCESSING object in the Objects panel.](/img/guides/configure-gradient-skybox/01_select-the-post-processing-object-in-the-objects-panel.png)

### Optional: Add the GradientSkybox component

> Use this section only if the GradientSkybox component is not already listed in the Properties panel. If it is already present, skip the actions in this section and continue with the main tutorial below.


2.1. Tap Add Component to add GradientSkybox.

![Tap Add Component to add GradientSkybox.](/img/guides/configure-gradient-skybox/02_tap-add-component-to-add-gradientskybox.png)

2.2. Open the Render category.

![Open the Render category.](/img/guides/configure-gradient-skybox/03_open-the-render-category.png)

2.3. Open the Skybox category.

![Open the Skybox category.](/img/guides/configure-gradient-skybox/04_open-the-skybox-category.png)

2.4. Select the GradientSkybox component.

![Select the GradientSkybox component.](/img/guides/configure-gradient-skybox/05_select-the-gradientskybox-component.png)

**End of optional section. Continue with the main tutorial below.**

2. Select the GradientSkybox component to view its settings.

![Select the GradientSkybox component to view its settings.](/img/guides/configure-gradient-skybox/06_select-the-gradientskybox-component-to-view-its-settings.png)

Gradient Skybox creates a simple colored scene background.

- **Top and bottom colors:** The colors from horizon to zenith.
- **Sun color, size, and position:** The appearance and location of the sun.
- **Brightness:** Visibility of the sky.
- **Resolution:** Sky quality.

3. GradientSkybox settings are visible in Properties.

![GradientSkybox settings are visible in Properties.](/img/guides/configure-gradient-skybox/07_gradientskybox-settings-are-visible-in-properties.png)

## Result

The GradientSkybox component is now configured and its settings are visible in the Properties panel. You can adjust its values and preview the result in your scene.
