# Configuring MotionBlur

Motion Blur softens moving parts of the image to convey speed.

Intensity controls blur. Samples improve smoothness. Velocity scale controls how movement affects the result.

## Steps

1. Select the POST PROCESSING object in the Objects panel.

![Select the POST PROCESSING object in the Objects panel.](/img/guides/motion-blur/01_select-the-post-processing-object-in-the-objects-panel.png)

### Optional: Add the MotionBlur component

> Use this section only if the MotionBlur component is not already listed in the Properties panel. If it is already present, skip the actions in this section and continue with the main tutorial below.


2.1. Tap Add Component to add MotionBlur.

![Tap Add Component to add MotionBlur.](/img/guides/motion-blur/02_tap-add-component-to-add-motionblur.png)

2.2. Open the Render category.

![Open the Render category.](/img/guides/motion-blur/03_open-the-render-category.png)

2.3. Open the Blur category.

![Open the Blur category.](/img/guides/motion-blur/04_open-the-blur-category.png)

2.4. Select the MotionBlur component.

![Select the MotionBlur component.](/img/guides/motion-blur/05_select-the-motionblur-component.png)

**End of optional section. Continue with the main tutorial below.**

2. Select the MotionBlur component to view its settings.

![Select the MotionBlur component to view its settings.](/img/guides/motion-blur/06_select-the-motionblur-component-to-view-its-settings.png)

Motion Blur softens moving parts to communicate speed.

- **Intensity:** Blur strength.
- **Samples:** Smoothness of the result.
- **Velocity scale:** How strongly movement affects the blur.

3. MotionBlur settings are visible in Properties.

![MotionBlur settings are visible in Properties.](/img/guides/motion-blur/07_motionblur-settings-are-visible-in-properties.png)

## Result

The MotionBlur component is now configured and its settings are visible in the Properties panel. You can adjust its values and preview the result in your scene.
