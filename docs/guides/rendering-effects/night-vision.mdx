# Configuring NightVision

Night Vision gives the image a low-light camera appearance.

Color chooses the tint. Brightness and contrast control visibility. Noise and scanlines add camera texture.

## Steps

1. Select the POST PROCESSING object in the Objects panel.

![Select the POST PROCESSING object in the Objects panel.](/img/guides/night-vision/01_select-the-post-processing-object-in-the-objects-panel.png)

### Optional: Add the NightVision component

> Use this section only if the NightVision component is not already listed in the Properties panel. If it is already present, skip the actions in this section and continue with the main tutorial below.


2.1. Tap Add Component to add NightVision.

![Tap Add Component to add NightVision.](/img/guides/night-vision/02_tap-add-component-to-add-nightvision.png)

2.2. Open the Render category.

![Open the Render category.](/img/guides/night-vision/03_open-the-render-category.png)

2.3. Open the Film category.

![Open the Film category.](/img/guides/night-vision/04_open-the-film-category.png)

2.4. Select the NightVision component.

![Select the NightVision component.](/img/guides/night-vision/05_select-the-nightvision-component.png)

**End of optional section. Continue with the main tutorial below.**

2. Select the NightVision component to view its settings.

![Select the NightVision component to view its settings.](/img/guides/night-vision/06_select-the-nightvision-component-to-view-its-settings.png)

Night Vision creates a low-light camera appearance.

- **Color:** Night-vision tint.
- **Brightness and contrast:** Visibility of the dark image.
- **Noise and scanlines:** Electronic camera texture.

3. NightVision settings are visible in Properties.

![NightVision settings are visible in Properties.](/img/guides/night-vision/07_nightvision-settings-are-visible-in-properties.png)

## Result

The NightVision component is now configured and its settings are visible in the Properties panel. You can adjust its values and preview the result in your scene.
