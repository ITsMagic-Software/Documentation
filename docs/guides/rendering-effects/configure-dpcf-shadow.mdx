# Configuring DPCF Shadow

DPCF Shadow adds filtered shadows with softer edges.

Shadow softness controls edge softness. Bias prevents artifacts. Resolution controls quality.

## Steps

1. Select the POST PROCESSING object in the Objects panel.

![Select the POST PROCESSING object in the Objects panel.](/img/guides/configure-dpcf-shadow/01_select-the-post-processing-object-in-the-objects-panel.png)

### Optional: Add the DPCFShadow component

> Use this section only if the DPCFShadow component is not already listed in the Properties panel. If it is already present, skip the actions in this section and continue with the main tutorial below.


2.1. Tap Add Component to add DPCF Shadow.

![Tap Add Component to add DPCF Shadow.](/img/guides/configure-dpcf-shadow/02_tap-add-component-to-add-dpcf-shadow.png)

2.2. Open the Render category.

![Open the Render category.](/img/guides/configure-dpcf-shadow/03_open-the-render-category.png)

2.3. Open the Lighting category.

![Open the Lighting category.](/img/guides/configure-dpcf-shadow/04_open-the-lighting-category.png)

2.4. Select the DPCF Shadow component.

![Select the DPCF Shadow component.](/img/guides/configure-dpcf-shadow/05_select-the-dpcf-shadow-component.png)

**End of optional section. Continue with the main tutorial below.**

2. Select the DPCF Shadow component to view its settings.

![Select the DPCF Shadow component to view its settings.](/img/guides/configure-dpcf-shadow/06_select-the-dpcf-shadow-component-to-view-its-settings.png)

DPCF Shadow creates filtered shadows with softer edges.

- **Shadow softness:** How soft the filtered edge appears.
- **Bias:** Moves the shadow slightly to reduce surface artifacts.
- **Resolution:** The quality of the shadow map.

3. DPCF Shadow settings are visible in Properties.

![DPCF Shadow settings are visible in Properties.](/img/guides/configure-dpcf-shadow/07_dpcf-shadow-settings-are-visible-in-properties.png)

## Result

The DPCF Shadow component is now configured and its settings are visible in the Properties panel. You can adjust its values and preview the result in your scene.
