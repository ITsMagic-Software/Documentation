# Configuring Saturation

Saturation controls how vivid the rendered colors appear.

Saturation increases color intensity or moves the image toward gray.

## Steps

1. Select the POST PROCESSING object in the Objects panel.

![Select the POST PROCESSING object in the Objects panel.](/img/guides/saturation/01_select-the-post-processing-object-in-the-objects-panel.png)

### Optional: Add the Saturation component

> Use this section only if the Saturation component is not already listed in the Properties panel. If it is already present, skip the actions in this section and continue with the main tutorial below.


2.1. Tap Add Component to add Saturation.

![Tap Add Component to add Saturation.](/img/guides/saturation/02_tap-add-component-to-add-saturation.png)

2.2. Open the Render category.

![Open the Render category.](/img/guides/saturation/03_open-the-render-category.png)

2.3. Open the Color grading category.

![Open the Color grading category.](/img/guides/saturation/04_open-the-color-grading-category.png)

2.4. Select the Saturation component.

![Select the Saturation component.](/img/guides/saturation/05_select-the-saturation-component.png)

**End of optional section. Continue with the main tutorial below.**

2. Select the Saturation component to view its settings.

![Select the Saturation component to view its settings.](/img/guides/saturation/06_select-the-saturation-component-to-view-its-settings.png)

Saturation controls color vividness.

- **Saturation:** Increases color intensity or moves the image toward gray.

3. Saturation settings are visible in Properties.

![Saturation settings are visible in Properties.](/img/guides/saturation/07_saturation-settings-are-visible-in-properties.png)

## Result

The Saturation component is now configured and its settings are visible in the Properties panel. You can adjust its values and preview the result in your scene.
