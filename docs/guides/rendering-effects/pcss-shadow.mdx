# Configuring PCSSShadow

PCSS Shadow produces soft shadows whose edges vary with distance.

Light size controls softness. Search and filter settings affect penumbra quality. Bias and resolution reduce artifacts.

## Steps

1. Select the POST PROCESSING object in the Objects panel.

![Select the POST PROCESSING object in the Objects panel.](/img/guides/pcss-shadow/01_select-the-post-processing-object-in-the-objects-panel.png)

### Optional: Add the PCSSShadow component

> Use this section only if the PCSSShadow component is not already listed in the Properties panel. If it is already present, skip the actions in this section and continue with the main tutorial below.


2.1. Tap Add Component to add PCSSShadow.

![Tap Add Component to add PCSSShadow.](/img/guides/pcss-shadow/02_tap-add-component-to-add-pcssshadow.png)

2.2. Open the Render category.

![Open the Render category.](/img/guides/pcss-shadow/03_open-the-render-category.png)

2.3. Open the Lighting category.

![Open the Lighting category.](/img/guides/pcss-shadow/04_open-the-lighting-category.png)

2.4. Select the PCSSShadow component.

![Select the PCSSShadow component.](/img/guides/pcss-shadow/05_select-the-pcssshadow-component.png)

**End of optional section. Continue with the main tutorial below.**

2. Select the PCSSShadow component to view its settings.

![Select the PCSSShadow component to view its settings.](/img/guides/pcss-shadow/06_select-the-pcssshadow-component-to-view-its-settings.png)

PCSS Shadow creates soft shadows whose edges vary with distance.

- **Light size:** Shadow softness.
- **Blocker search and filter settings:** Penumbra quality.
- **Bias:** Reduces shadow artifacts.
- **Resolution:** Shadow detail.

3. PCSSShadow settings are visible in Properties.

![PCSSShadow settings are visible in Properties.](/img/guides/pcss-shadow/07_pcssshadow-settings-are-visible-in-properties.png)

## Result

The PCSSShadow component is now configured and its settings are visible in the Properties panel. You can adjust its values and preview the result in your scene.
