# Configuring Chromatic Aberration

Chromatic Aberration separates color edges to imitate a camera lens imperfection.

Strength controls color separation near edges. Falloff controls fading toward the center.

## Steps

1. Select the POST PROCESSING object in the Objects panel.

![Select the POST PROCESSING object in the Objects panel.](/img/guides/configure-chromatic-aberration/01_select-the-post-processing-object-in-the-objects-panel.png)

### Optional: Add the ChromaticAberration component

> Use this section only if the ChromaticAberration component is not already listed in the Properties panel. If it is already present, skip the actions in this section and continue with the main tutorial below.


2.1. Tap Add Component to add Chromatic Aberration.

![Tap Add Component to add Chromatic Aberration.](/img/guides/configure-chromatic-aberration/02_tap-add-component-to-add-chromatic-aberration.png)

2.2. Open the Render category.

![Open the Render category.](/img/guides/configure-chromatic-aberration/03_open-the-render-category.png)

2.3. Open the Lens category.

![Open the Lens category.](/img/guides/configure-chromatic-aberration/04_open-the-lens-category.png)

2.4. Select the Chromatic Aberration component.

![Select the Chromatic Aberration component.](/img/guides/configure-chromatic-aberration/05_select-the-chromatic-aberration-component.png)

**End of optional section. Continue with the main tutorial below.**

2. Select the Chromatic Aberration component to view its settings.

![Select the Chromatic Aberration component to view its settings.](/img/guides/configure-chromatic-aberration/06_select-the-chromatic-aberration-component-to-view-its-settings.png)

Chromatic Aberration imitates color separation from a camera lens.

- **Strength:** The amount of red, green, and blue separation.
- **Falloff:** How quickly the effect fades toward the image center.

3. Chromatic Aberration settings are visible in Properties.

![Chromatic Aberration settings are visible in Properties.](/img/guides/configure-chromatic-aberration/07_chromatic-aberration-settings-are-visible-in-properties.png)

## Result

The Chromatic Aberration component is now configured and its settings are visible in the Properties panel. You can adjust its values and preview the result in your scene.
