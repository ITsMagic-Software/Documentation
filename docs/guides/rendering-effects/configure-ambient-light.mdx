# Configuring AmbientLight

Ambient light adds soft illumination to areas that are not directly lit.

Indirect light sets soft fill illumination. Lux controls its strength. Color tints it. Resolution controls quality.

## Steps

1. Select the POST PROCESSING object in the Objects panel.

![Select the POST PROCESSING object in the Objects panel.](/img/guides/configure-ambient-light/01_select-the-post-processing-object-in-the-objects-panel.png)

### Optional: Add the AmbientLight component

> Use this section only if the AmbientLight component is not already listed in the Properties panel. If it is already present, skip the actions in this section and continue with the main tutorial below.


**End of optional section. Continue with the main tutorial below.**

2. Select the AmbientLight component to view its settings.

![Select the AmbientLight component to view its settings.](/img/guides/configure-ambient-light/02_select-the-ambientlight-component-to-view-its-settings.png)

The Ambient Light controls add soft illumination to the scene.

- **Indirect light:** How much fill light reaches areas that are not directly lit.
- **Lux:** The strength of the ambient light.
- **Color:** The tint of the ambient light.
- **Resolution:** The quality used for the lighting calculation.

3. AmbientLight settings are visible in the Properties panel.

![AmbientLight settings are visible in the Properties panel.](/img/guides/configure-ambient-light/03_ambientlight-settings-are-visible-in-the-properties-panel.png)

## Result

The AmbientLight component is now configured and its settings are visible in the Properties panel. You can adjust its values and preview the result in your scene.
