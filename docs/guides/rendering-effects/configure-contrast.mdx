# Configuring Contrast

Contrast changes the difference between light and dark areas.

Contrast changes the difference between light and dark areas.

## Steps

1. Select the POST PROCESSING object in the Objects panel.

![Select the POST PROCESSING object in the Objects panel.](/img/guides/configure-contrast/01_select-the-post-processing-object-in-the-objects-panel.png)

### Optional: Add the Contrast component

> Use this section only if the Contrast component is not already listed in the Properties panel. If it is already present, skip the actions in this section and continue with the main tutorial below.


2.1. Tap Add Component to add Contrast.

![Tap Add Component to add Contrast.](/img/guides/configure-contrast/02_tap-add-component-to-add-contrast.png)

2.2. Open the Render category.

![Open the Render category.](/img/guides/configure-contrast/03_open-the-render-category.png)

2.3. Open the Color grading category.

![Open the Color grading category.](/img/guides/configure-contrast/04_open-the-color-grading-category.png)

2.4. Select the Contrast component.

![Select the Contrast component.](/img/guides/configure-contrast/05_select-the-contrast-component.png)

**End of optional section. Continue with the main tutorial below.**

2. Select the Contrast component to view its settings.

![Select the Contrast component to view its settings.](/img/guides/configure-contrast/06_select-the-contrast-component-to-view-its-settings.png)

Contrast changes the separation between light and dark areas.

- **Contrast:** Higher values make differences stronger; lower values flatten the image.

3. Contrast settings are visible in Properties.

![Contrast settings are visible in Properties.](/img/guides/configure-contrast/07_contrast-settings-are-visible-in-properties.png)

## Result

The Contrast component is now configured and its settings are visible in the Properties panel. You can adjust its values and preview the result in your scene.
