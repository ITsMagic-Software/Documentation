# Configuring Fog

Fog places a colored haze in the scene so distant objects gradually disappear.

Color chooses fog color. Density controls how quickly it hides objects. Start, end, height, and falloff define its range.

## Steps

1. Select the POST PROCESSING object in the Objects panel.

![Select the POST PROCESSING object in the Objects panel.](/img/guides/configure-fog/01_select-the-post-processing-object-in-the-objects-panel.png)

### Optional: Add the Fog component

> Use this section only if the Fog component is not already listed in the Properties panel. If it is already present, skip the actions in this section and continue with the main tutorial below.


2.1. Tap Add Component to add Fog.

![Tap Add Component to add Fog.](/img/guides/configure-fog/02_tap-add-component-to-add-fog.png)

2.2. Open the Render category.

![Open the Render category.](/img/guides/configure-fog/03_open-the-render-category.png)

2.3. Open the Volumetric category.

![Open the Volumetric category.](/img/guides/configure-fog/04_open-the-volumetric-category.png)

2.4. Select the Fog component.

![Select the Fog component.](/img/guides/configure-fog/05_select-the-fog-component.png)

**End of optional section. Continue with the main tutorial below.**

2. Select the Fog component to view its settings.

![Select the Fog component to view its settings.](/img/guides/configure-fog/06_select-the-fog-component-to-view-its-settings.png)

Fog adds a colored haze that hides distant objects.

- **Color:** Fog color.
- **Density:** How quickly objects disappear into fog.
- **Start and end distance:** Where fog begins and reaches full strength.
- **Height and falloff:** How fog changes with world height.

3. Fog settings are visible in Properties.

![Fog settings are visible in Properties.](/img/guides/configure-fog/07_fog-settings-are-visible-in-properties.png)

## Result

The Fog component is now configured and its settings are visible in the Properties panel. You can adjust its values and preview the result in your scene.
