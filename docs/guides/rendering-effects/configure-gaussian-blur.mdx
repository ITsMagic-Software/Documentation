# Configuring GaussianBlur

Gaussian Blur softly blurs the whole image.

Blur size controls softening. Quality and resolution balance smoothness and performance.

## Steps

1. Select the POST PROCESSING object in the Objects panel.

![Select the POST PROCESSING object in the Objects panel.](/img/guides/configure-gaussian-blur/01_select-the-post-processing-object-in-the-objects-panel.png)

### Optional: Add the GaussianBlur component

> Use this section only if the GaussianBlur component is not already listed in the Properties panel. If it is already present, skip the actions in this section and continue with the main tutorial below.


2.1. Tap Add Component to add GaussianBlur.

![Tap Add Component to add GaussianBlur.](/img/guides/configure-gaussian-blur/02_tap-add-component-to-add-gaussianblur.png)

2.2. Open the Render category.

![Open the Render category.](/img/guides/configure-gaussian-blur/03_open-the-render-category.png)

2.3. Open the Blur category.

![Open the Blur category.](/img/guides/configure-gaussian-blur/04_open-the-blur-category.png)

2.4. Select the GaussianBlur component.

![Select the GaussianBlur component.](/img/guides/configure-gaussian-blur/05_select-the-gaussianblur-component.png)

**End of optional section. Continue with the main tutorial below.**

2. Select the GaussianBlur component to view its settings.

![Select the GaussianBlur component to view its settings.](/img/guides/configure-gaussian-blur/06_select-the-gaussianblur-component-to-view-its-settings.png)

Gaussian Blur softly smooths the complete image.

- **Blur size:** The width of the softening.
- **Quality and resolution:** Smoothness versus performance.

3. GaussianBlur settings are visible in Properties.

![GaussianBlur settings are visible in Properties.](/img/guides/configure-gaussian-blur/07_gaussianblur-settings-are-visible-in-properties.png)

## Result

The GaussianBlur component is now configured and its settings are visible in the Properties panel. You can adjust its values and preview the result in your scene.
