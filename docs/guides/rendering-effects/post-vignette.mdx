# Configuring PostVignette

Post Vignette darkens or colors the image corners.

Color tints corners. Intensity controls strength. Radius and softness set where it starts and fades.

## Steps

1. Select the POST PROCESSING object in the Objects panel.

![Select the POST PROCESSING object in the Objects panel.](/img/guides/post-vignette/01_select-the-post-processing-object-in-the-objects-panel.png)

### Optional: Add the PostVignette component

> Use this section only if the PostVignette component is not already listed in the Properties panel. If it is already present, skip the actions in this section and continue with the main tutorial below.


2.1. Tap Add Component to add PostVignette.

![Tap Add Component to add PostVignette.](/img/guides/post-vignette/02_tap-add-component-to-add-postvignette.png)

2.2. Open the Render category.

![Open the Render category.](/img/guides/post-vignette/03_open-the-render-category.png)

2.3. Open the Lens category.

![Open the Lens category.](/img/guides/post-vignette/04_open-the-lens-category.png)

2.4. Select the PostVignette component.

![Select the PostVignette component.](/img/guides/post-vignette/05_select-the-postvignette-component.png)

**End of optional section. Continue with the main tutorial below.**

2. Select the PostVignette component to view its settings.

![Select the PostVignette component to view its settings.](/img/guides/post-vignette/06_select-the-postvignette-component-to-view-its-settings.png)

Post Vignette focuses attention toward the center of the image.

- **Color:** Corner tint.
- **Intensity:** Strength of the corners.
- **Radius:** Where the effect begins.
- **Softness:** How gently it fades.

3. PostVignette settings are visible in Properties.

![PostVignette settings are visible in Properties.](/img/guides/post-vignette/07_postvignette-settings-are-visible-in-properties.png)

## Result

The PostVignette component is now configured and its settings are visible in the Properties panel. You can adjust its values and preview the result in your scene.
