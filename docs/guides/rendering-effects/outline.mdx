# Configuring Outline

Outline draws lines around visible object edges.

Color chooses the line. Thickness controls width. Depth and normal sensitivity choose edges. Threshold filters weak edges.

## Steps

1. Select the POST PROCESSING object in the Objects panel.

![Select the POST PROCESSING object in the Objects panel.](/img/guides/outline/01_select-the-post-processing-object-in-the-objects-panel.png)

### Optional: Add the Outline component

> Use this section only if the Outline component is not already listed in the Properties panel. If it is already present, skip the actions in this section and continue with the main tutorial below.


2.1. Tap Add Component to add Outline.

![Tap Add Component to add Outline.](/img/guides/outline/02_tap-add-component-to-add-outline.png)

2.2. Open the Render category.

![Open the Render category.](/img/guides/outline/03_open-the-render-category.png)

2.3. Open the Highlights category.

![Open the Highlights category.](/img/guides/outline/04_open-the-highlights-category.png)

2.4. Select the Outline component.

![Select the Outline component.](/img/guides/outline/05_select-the-outline-component.png)

**End of optional section. Continue with the main tutorial below.**

2. Select the Outline component to view its settings.

![Select the Outline component to view its settings.](/img/guides/outline/06_select-the-outline-component-to-view-its-settings.png)

Outline draws lines around object edges.

- **Color:** Line color.
- **Thickness:** Line width.
- **Depth and normal sensitivity:** Which edges qualify.
- **Threshold:** Filters weak edges.

3. Outline settings are visible in Properties.

![Outline settings are visible in Properties.](/img/guides/outline/07_outline-settings-are-visible-in-properties.png)

## Result

The Outline component is now configured and its settings are visible in the Properties panel. You can adjust its values and preview the result in your scene.
