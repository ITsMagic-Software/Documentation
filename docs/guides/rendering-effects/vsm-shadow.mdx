# Configuring VSMShadow

VSM Shadow adds filtered shadows with smooth edges.

Shadow softness controls edge softness. Bias prevents artifacts. Resolution controls quality.

## Steps

1. Select the POST PROCESSING object in the Objects panel.

![Select the POST PROCESSING object in the Objects panel.](/img/guides/vsm-shadow/01_select-the-post-processing-object-in-the-objects-panel.png)

### Optional: Add the VSMShadow component

> Use this section only if the VSMShadow component is not already listed in the Properties panel. If it is already present, skip the actions in this section and continue with the main tutorial below.


2.1. Tap Add Component to add VSMShadow.

![Tap Add Component to add VSMShadow.](/img/guides/vsm-shadow/02_tap-add-component-to-add-vsmshadow.png)

2.2. Open the Render category.

![Open the Render category.](/img/guides/vsm-shadow/03_open-the-render-category.png)

2.3. Open the Lighting category.

![Open the Lighting category.](/img/guides/vsm-shadow/04_open-the-lighting-category.png)

2.4. Select the VSMShadow component.

![Select the VSMShadow component.](/img/guides/vsm-shadow/05_select-the-vsmshadow-component.png)

**End of optional section. Continue with the main tutorial below.**

2. Select the VSMShadow component to view its settings.

![Select the VSMShadow component to view its settings.](/img/guides/vsm-shadow/06_select-the-vsmshadow-component-to-view-its-settings.png)

VSM Shadow creates filtered shadows with smooth edges.

- **Shadow softness:** Edge softness.
- **Bias:** Reduces shadow artifacts.
- **Resolution:** Shadow quality.

3. VSMShadow settings are visible in Properties.

![VSMShadow settings are visible in Properties.](/img/guides/vsm-shadow/07_vsmshadow-settings-are-visible-in-properties.png)

## Result

The VSMShadow component is now configured and its settings are visible in the Properties panel. You can adjust its values and preview the result in your scene.
