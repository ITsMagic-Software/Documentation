# Configuring Halftone

Halftone converts the image into a printed-dot pattern.

Size controls dot spacing. Threshold controls dark dots. Color tints the pattern.

## Steps

1. Select the POST PROCESSING object in the Objects panel.

![Select the POST PROCESSING object in the Objects panel.](/img/guides/configure-halftone/01_select-the-post-processing-object-in-the-objects-panel.png)

### Optional: Add the Halftone component

> Use this section only if the Halftone component is not already listed in the Properties panel. If it is already present, skip the actions in this section and continue with the main tutorial below.


2.1. Tap Add Component to add Halftone.

![Tap Add Component to add Halftone.](/img/guides/configure-halftone/02_tap-add-component-to-add-halftone.png)

2.2. Open the Render category.

![Open the Render category.](/img/guides/configure-halftone/03_open-the-render-category.png)

2.3. Open the Stylized category.

![Open the Stylized category.](/img/guides/configure-halftone/04_open-the-stylized-category.png)

2.4. Select the Halftone component.

![Select the Halftone component.](/img/guides/configure-halftone/05_select-the-halftone-component.png)

**End of optional section. Continue with the main tutorial below.**

2. Select the Halftone component to view its settings.

![Select the Halftone component to view its settings.](/img/guides/configure-halftone/06_select-the-halftone-component-to-view-its-settings.png)

Halftone creates a comic or newspaper dot pattern.

- **Size:** Dot spacing.
- **Threshold:** Which tones become darker dots.
- **Color:** The tint of the pattern.

3. Halftone settings are visible in Properties.

![Halftone settings are visible in Properties.](/img/guides/configure-halftone/07_halftone-settings-are-visible-in-properties.png)

## Result

The Halftone component is now configured and its settings are visible in the Properties panel. You can adjust its values and preview the result in your scene.
