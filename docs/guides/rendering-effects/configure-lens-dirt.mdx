# Configuring LensDirt

Lens Dirt overlays marks on the camera lens, especially over bright areas.

The dirt texture supplies lens marks. Intensity controls visibility. Threshold limits the effect to bright areas. Color tints it.

## Steps

1. Select the POST PROCESSING object in the Objects panel.

![Select the POST PROCESSING object in the Objects panel.](/img/guides/configure-lens-dirt/01_select-the-post-processing-object-in-the-objects-panel.png)

### Optional: Add the LensDirt component

> Use this section only if the LensDirt component is not already listed in the Properties panel. If it is already present, skip the actions in this section and continue with the main tutorial below.


2.1. Tap Add Component to add LensDirt.

![Tap Add Component to add LensDirt.](/img/guides/configure-lens-dirt/02_tap-add-component-to-add-lensdirt.png)

2.2. Open the Render category.

![Open the Render category.](/img/guides/configure-lens-dirt/03_open-the-render-category.png)

2.3. Open the Lens category.

![Open the Lens category.](/img/guides/configure-lens-dirt/04_open-the-lens-category.png)

2.4. Select the LensDirt component.

![Select the LensDirt component.](/img/guides/configure-lens-dirt/05_select-the-lensdirt-component.png)

**End of optional section. Continue with the main tutorial below.**

2. Select the LensDirt component to view its settings.

![Select the LensDirt component to view its settings.](/img/guides/configure-lens-dirt/06_select-the-lensdirt-component-to-view-its-settings.png)

Lens Dirt places marks over bright areas as if they were on a camera lens.

- **Dirt texture:** The image used for the marks.
- **Intensity:** How visible the marks are.
- **Threshold:** Which bright areas reveal them.
- **Color:** Their tint.

3. LensDirt settings are visible in Properties.

![LensDirt settings are visible in Properties.](/img/guides/configure-lens-dirt/07_lensdirt-settings-are-visible-in-properties.png)

## Result

The LensDirt component is now configured and its settings are visible in the Properties panel. You can adjust its values and preview the result in your scene.
