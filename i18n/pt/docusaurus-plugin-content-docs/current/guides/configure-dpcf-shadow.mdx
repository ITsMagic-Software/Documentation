# Como configurar DPCF Shadow

Este guia mostra como configurar o componente DPCF Shadow no objeto POST PROCESSING. Siga os passos abaixo e ajuste as configurações para obter o resultado desejado na cena.

## Passos

1. Selecione o objeto POST PROCESSING no painel Objects.

![Selecione o objeto POST PROCESSING no painel Objects.](/img/guides/configure-dpcf-shadow/01_select-the-post-processing-object-in-the-objects-panel.png)

### Opcional: Adicione o componente DPCFShadow

> Use esta seção somente se o componente ainda não estiver listado no painel Properties. Se ele já estiver presente, ignore as ações desta seção e continue com o tutorial principal abaixo.

2.1. Toque em Add Component para adicionar DPCF Shadow.

![Toque em Add Component para adicionar DPCF Shadow.](/img/guides/configure-dpcf-shadow/02_tap-add-component-to-add-dpcf-shadow.png)

2.2. Abra a categoria Render.

![Abra a categoria Render.](/img/guides/configure-dpcf-shadow/03_open-the-render-category.png)

2.3. Abra a categoria Lighting.

![Abra a categoria Lighting.](/img/guides/configure-dpcf-shadow/04_open-the-lighting-category.png)

2.4. Selecione o componente DPCF Shadow.

![Selecione o componente DPCF Shadow.](/img/guides/configure-dpcf-shadow/05_select-the-dpcf-shadow-component.png)

**Fim da seção opcional. Continue com o tutorial principal abaixo.**

2. Selecione o componente DPCF Shadow para visualizar suas configurações.

![Selecione o componente DPCF Shadow para visualizar suas configurações.](/img/guides/configure-dpcf-shadow/06_select-the-dpcf-shadow-component-to-view-its-settings.png)

As configurações de 3. DPCF Shadow estão visíveis em Properties.

![As configurações de DPCF Shadow estão visíveis em Properties.](/img/guides/configure-dpcf-shadow/07_dpcf-shadow-settings-are-visible-in-properties.png)

## Resultado

O componente DPCF Shadow está configurado e suas opções estão visíveis no painel Properties. Você pode ajustar os valores e visualizar o resultado na cena.
