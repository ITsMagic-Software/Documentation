# Como configurar VHSFilter

Este guia mostra como configurar o componente VHSFilter no objeto POST PROCESSING. Siga os passos abaixo e ajuste as configurações para obter o resultado desejado na cena.

## Passos

1. Selecione o objeto POST PROCESSING no painel Objects.

![Selecione o objeto POST PROCESSING no painel Objects.](/img/guides/vhs-filter/01_select-the-post-processing-object-in-the-objects-panel.png)

### Opcional: Adicione o componente VHSFilter

> Use esta seção somente se o componente ainda não estiver listado no painel Properties. Se ele já estiver presente, ignore as ações desta seção e continue com o tutorial principal abaixo.

2.1. Toque em Add Component para adicionar VHSFilter.

![Toque em Add Component para adicionar VHSFilter.](/img/guides/vhs-filter/02_tap-add-component-to-add-vhsfilter.png)

2.2. Abra a categoria Render.

![Abra a categoria Render.](/img/guides/vhs-filter/03_open-the-render-category.png)

2.3. Abra a categoria Film.

![Abra a categoria Film.](/img/guides/vhs-filter/04_open-the-film-category.png)

2.4. Selecione o componente VHSFilter.

![Selecione o componente VHSFilter.](/img/guides/vhs-filter/05_select-the-vhsfilter-component.png)

**Fim da seção opcional. Continue com o tutorial principal abaixo.**

2. Selecione o componente VHSFilter para visualizar suas configurações.

![Selecione o componente VHSFilter para visualizar suas configurações.](/img/guides/vhs-filter/06_select-the-vhsfilter-component-to-view-its-settings.png)

As configurações de 3. VHSFilter estão visíveis em Properties.

![As configurações de VHSFilter estão visíveis em Properties.](/img/guides/vhs-filter/07_vhsfilter-settings-are-visible-in-properties.png)

## Resultado

O componente VHSFilter está configurado e suas opções estão visíveis no painel Properties. Você pode ajustar os valores e visualizar o resultado na cena.
