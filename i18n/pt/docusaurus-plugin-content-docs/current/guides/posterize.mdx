# Como configurar Posterize

Este guia mostra como configurar o componente Posterize no objeto POST PROCESSING. Siga os passos abaixo e ajuste as configurações para obter o resultado desejado na cena.

## Passos

1. Selecione o objeto POST PROCESSING no painel Objects.

![Selecione o objeto POST PROCESSING no painel Objects.](/img/guides/posterize/01_select-the-post-processing-object-in-the-objects-panel.png)

### Opcional: Adicione o componente Posterize

> Use esta seção somente se o componente ainda não estiver listado no painel Properties. Se ele já estiver presente, ignore as ações desta seção e continue com o tutorial principal abaixo.

2.1. Toque em Add Component para adicionar Posterize.

![Toque em Add Component para adicionar Posterize.](/img/guides/posterize/02_tap-add-component-to-add-posterize.png)

2.2. Abra a categoria Render.

![Abra a categoria Render.](/img/guides/posterize/03_open-the-render-category.png)

2.3. Abra a categoria Stylized.

![Abra a categoria Stylized.](/img/guides/posterize/04_open-the-stylized-category.png)

2.4. Selecione o componente Posterize.

![Selecione o componente Posterize.](/img/guides/posterize/05_select-the-posterize-component.png)

**Fim da seção opcional. Continue com o tutorial principal abaixo.**

2. Selecione o componente Posterize para visualizar suas configurações.

![Selecione o componente Posterize para visualizar suas configurações.](/img/guides/posterize/06_select-the-posterize-component-to-view-its-settings.png)

As configurações de 3. Posterize estão visíveis em Properties.

![As configurações de Posterize estão visíveis em Properties.](/img/guides/posterize/07_posterize-settings-are-visible-in-properties.png)

## Resultado

O componente Posterize está configurado e suas opções estão visíveis no painel Properties. Você pode ajustar os valores e visualizar o resultado na cena.
