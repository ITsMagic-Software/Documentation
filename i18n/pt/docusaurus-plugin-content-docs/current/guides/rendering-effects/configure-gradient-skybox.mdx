# Como configurar GradientSkybox

Este guia mostra como configurar o componente GradientSkybox no objeto POST PROCESSING. Siga os passos abaixo e ajuste as configurações para obter o resultado desejado na cena.

## Passos

1. Selecione o objeto POST PROCESSING no painel Objects.

![Selecione o objeto POST PROCESSING no painel Objects.](/img/guides/configure-gradient-skybox/01_select-the-post-processing-object-in-the-objects-panel.png)

### Opcional: Adicione o componente GradientSkybox

> Use esta seção somente se o componente ainda não estiver listado no painel Properties. Se ele já estiver presente, ignore as ações desta seção e continue com o tutorial principal abaixo.

2.1. Toque em Add Component para adicionar GradientSkybox.

![Toque em Add Component para adicionar GradientSkybox.](/img/guides/configure-gradient-skybox/02_tap-add-component-to-add-gradientskybox.png)

2.2. Abra a categoria Render.

![Abra a categoria Render.](/img/guides/configure-gradient-skybox/03_open-the-render-category.png)

2.3. Abra a categoria Skybox.

![Abra a categoria Skybox.](/img/guides/configure-gradient-skybox/04_open-the-skybox-category.png)

2.4. Selecione o componente GradientSkybox.

![Selecione o componente GradientSkybox.](/img/guides/configure-gradient-skybox/05_select-the-gradientskybox-component.png)

**Fim da seção opcional. Continue com o tutorial principal abaixo.**

2. Selecione o componente GradientSkybox para visualizar suas configurações.

![Selecione o componente GradientSkybox para visualizar suas configurações.](/img/guides/configure-gradient-skybox/06_select-the-gradientskybox-component-to-view-its-settings.png)

As configurações de 3. GradientSkybox estão visíveis em Properties.

![As configurações de GradientSkybox estão visíveis em Properties.](/img/guides/configure-gradient-skybox/07_gradientskybox-settings-are-visible-in-properties.png)

## Resultado

O componente GradientSkybox está configurado e suas opções estão visíveis no painel Properties. Você pode ajustar os valores e visualizar o resultado na cena.
