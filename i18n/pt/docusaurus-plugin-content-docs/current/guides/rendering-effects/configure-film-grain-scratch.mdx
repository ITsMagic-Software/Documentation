# Como configurar FilmGrainScratch

Este guia mostra como configurar o componente FilmGrainScratch no objeto POST PROCESSING. Siga os passos abaixo e ajuste as configurações para obter o resultado desejado na cena.

## Passos

1. Selecione o objeto POST PROCESSING no painel Objects.

![Selecione o objeto POST PROCESSING no painel Objects.](/img/guides/configure-film-grain-scratch/01_select-the-post-processing-object-in-the-objects-panel.png)

### Opcional: Adicione o componente FilmGrainScratch

> Use esta seção somente se o componente ainda não estiver listado no painel Properties. Se ele já estiver presente, ignore as ações desta seção e continue com o tutorial principal abaixo.

2.1. Toque em Add Component para adicionar FilmGrainScratch.

![Toque em Add Component para adicionar FilmGrainScratch.](/img/guides/configure-film-grain-scratch/02_tap-add-component-to-add-filmgrainscratch.png)

2.2. Abra a categoria Render.

![Abra a categoria Render.](/img/guides/configure-film-grain-scratch/03_open-the-render-category.png)

2.3. Abra a categoria Film.

![Abra a categoria Film.](/img/guides/configure-film-grain-scratch/04_open-the-film-category.png)

2.4. Selecione o componente FilmGrainScratch.

![Selecione o componente FilmGrainScratch.](/img/guides/configure-film-grain-scratch/05_select-the-filmgrainscratch-component.png)

**Fim da seção opcional. Continue com o tutorial principal abaixo.**

2. Selecione o componente FilmGrainScratch para visualizar suas configurações.

![Selecione o componente FilmGrainScratch para visualizar suas configurações.](/img/guides/configure-film-grain-scratch/06_select-the-filmgrainscratch-component-to-view-its-settings.png)

As configurações de 3. FilmGrainScratch estão visíveis em Properties.

![As configurações de FilmGrainScratch estão visíveis em Properties.](/img/guides/configure-film-grain-scratch/07_filmgrainscratch-settings-are-visible-in-properties.png)

## Resultado

O componente FilmGrainScratch está configurado e suas opções estão visíveis no painel Properties. Você pode ajustar os valores e visualizar o resultado na cena.
