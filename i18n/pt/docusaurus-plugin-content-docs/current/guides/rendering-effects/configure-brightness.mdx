# Como configurar Brightness

Este guia mostra como configurar o componente Brightness no objeto POST PROCESSING. Siga os passos abaixo e ajuste as configurações para obter o resultado desejado na cena.

## Passos

1. Selecione o objeto POST PROCESSING no painel Objects.

![Selecione o objeto POST PROCESSING no painel Objects.](/img/guides/configure-brightness/01_select-the-post-processing-object-in-the-objects-panel.png)

### Opcional: Adicione o componente Brightness

> Use esta seção somente se o componente ainda não estiver listado no painel Properties. Se ele já estiver presente, ignore as ações desta seção e continue com o tutorial principal abaixo.

2.1. Toque em Add Component para adicionar Brightness.

![Toque em Add Component para adicionar Brightness.](/img/guides/configure-brightness/02_tap-add-component-to-add-brightness.png)

2.2. Abra a categoria Render.

![Abra a categoria Render.](/img/guides/configure-brightness/03_open-the-render-category.png)

2.3. Abra a categoria Color grading.

![Abra a categoria Color grading.](/img/guides/configure-brightness/04_open-the-color-grading-category.png)

2.4. Selecione o componente Brightness.

![Selecione o componente Brightness.](/img/guides/configure-brightness/05_select-the-brightness-component.png)

**Fim da seção opcional. Continue com o tutorial principal abaixo.**

2. Selecione o componente Brightness para visualizar suas configurações.

![Selecione o componente Brightness para visualizar suas configurações.](/img/guides/configure-brightness/06_select-the-brightness-component-to-view-its-settings.png)

As configurações de 3. Brightness estão visíveis no painel Properties.

![As configurações de Brightness estão visíveis no painel Properties.](/img/guides/configure-brightness/07_brightness-settings-are-visible-in-the-properties-panel.png)

## Resultado

O componente Brightness está configurado e suas opções estão visíveis no painel Properties. Você pode ajustar os valores e visualizar o resultado na cena.
