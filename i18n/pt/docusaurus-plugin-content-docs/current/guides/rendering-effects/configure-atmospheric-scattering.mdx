# Como configurar AtmosphericScattering

Este guia mostra como configurar o componente AtmosphericScattering no objeto POST PROCESSING. Siga os passos abaixo e ajuste as configurações para obter o resultado desejado na cena.

## Passos

1. Selecione o objeto POST PROCESSING no painel Objects.

![Selecione o objeto POST PROCESSING no painel Objects.](/img/guides/configure-atmospheric-scattering/01_select-the-post-processing-object-in-the-objects-panel.png)

### Opcional: Adicione o componente AtmosphericScattering

> Use esta seção somente se o componente ainda não estiver listado no painel Properties. Se ele já estiver presente, ignore as ações desta seção e continue com o tutorial principal abaixo.

2.1. Toque em Add Component para adicionar AtmosphericScattering.

![Toque em Add Component para adicionar AtmosphericScattering.](/img/guides/configure-atmospheric-scattering/02_tap-add-component-to-add-atmosphericscattering.png)

2.2. Abra a categoria Render.

![Abra a categoria Render.](/img/guides/configure-atmospheric-scattering/03_open-the-render-category.png)

2.3. Abra a categoria Skybox.

![Abra a categoria Skybox.](/img/guides/configure-atmospheric-scattering/04_open-the-skybox-category.png)

2.4. Selecione o componente AtmosphericScattering.

![Selecione o componente AtmosphericScattering.](/img/guides/configure-atmospheric-scattering/05_select-the-atmosphericscattering-component.png)

**Fim da seção opcional. Continue com o tutorial principal abaixo.**

2. Selecione o componente AtmosphericScattering para visualizar suas configurações.

![Selecione o componente AtmosphericScattering para visualizar suas configurações.](/img/guides/configure-atmospheric-scattering/06_select-the-atmosphericscattering-component-to-view-its-settings.png)

As configurações de 3. AtmosphericScattering estão visíveis no painel Properties.

![As configurações de AtmosphericScattering estão visíveis no painel Properties.](/img/guides/configure-atmospheric-scattering/07_atmosphericscattering-settings-are-visible-in-the-properties-panel.png)

## Resultado

O componente AtmosphericScattering está configurado e suas opções estão visíveis no painel Properties. Você pode ajustar os valores e visualizar o resultado na cena.
