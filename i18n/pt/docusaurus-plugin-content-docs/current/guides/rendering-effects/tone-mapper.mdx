# Como configurar ToneMapper

Este guia mostra como configurar o componente ToneMapper no objeto POST PROCESSING. Siga os passos abaixo e ajuste as configurações para obter o resultado desejado na cena.

## Passos

1. Selecione o objeto POST PROCESSING no painel Objects.

![Selecione o objeto POST PROCESSING no painel Objects.](/img/guides/tone-mapper/01_select-the-post-processing-object-in-the-objects-panel.png)

### Opcional: Adicione o componente ToneMapper

> Use esta seção somente se o componente ainda não estiver listado no painel Properties. Se ele já estiver presente, ignore as ações desta seção e continue com o tutorial principal abaixo.

**Fim da seção opcional. Continue com o tutorial principal abaixo.**

2. Selecione o componente ToneMapper para visualizar suas configurações.

![Selecione o componente ToneMapper para visualizar suas configurações.](/img/guides/tone-mapper/02_select-the-tonemapper-component-to-view-its-settings.png)

As configurações de 3. ToneMapper estão visíveis em Properties.

![As configurações de ToneMapper estão visíveis em Properties.](/img/guides/tone-mapper/03_tonemapper-settings-are-visible-in-properties.png)

## Resultado

O componente ToneMapper está configurado e suas opções estão visíveis no painel Properties. Você pode ajustar os valores e visualizar o resultado na cena.
