# Como configurar a scene skybox

Este guia mostra como configurar o componente a scene skybox no objeto POST PROCESSING. Siga os passos abaixo e ajuste as configurações para obter o resultado desejado na cena.

## Passos

1. Selecione o objeto POST PROCESSING no painel Objects.

![Selecione o objeto POST PROCESSING no painel Objects.](/img/guides/configure-skybox/01_select-the-post-processing-object-in-the-objects-panel.png)

### Opcional: Adicione o componente Skybox

> Use esta seção somente se o componente ainda não estiver listado no painel Properties. Se ele já estiver presente, ignore as ações desta seção e continue com o tutorial principal abaixo.

2.1. Toque em Add Component to begin adding Skybox.

![Toque em Add Component to begin adding Skybox.](/img/guides/configure-skybox/02_tap-add-component-to-begin-adding-skybox.png)

2.2. Abra a categoria Render.

![Abra a categoria Render.](/img/guides/configure-skybox/03_open-the-render-category.png)

2.3. Abra a categoria Skybox.

![Abra a categoria Skybox.](/img/guides/configure-skybox/04_open-the-skybox-category.png)

2.4. Selecione o componente Skybox.

![Selecione o componente Skybox.](/img/guides/configure-skybox/05_select-the-skybox-component.png)

**Fim da seção opcional. Continue com o tutorial principal abaixo.**

2. Selecione o componente Skybox para visualizar suas configurações.

![Selecione o componente Skybox para visualizar suas configurações.](/img/guides/configure-skybox/06_select-the-skybox-component-to-view-its-settings.png)

As configurações de 3. Skybox estão visíveis no painel Properties.

![As configurações de Skybox estão visíveis no painel Properties.](/img/guides/configure-skybox/07_skybox-settings-are-visible-in-the-properties-panel.png)

## Resultado

O componente a scene skybox está configurado e suas opções estão visíveis no painel Properties. Você pode ajustar os valores e visualizar o resultado na cena.
