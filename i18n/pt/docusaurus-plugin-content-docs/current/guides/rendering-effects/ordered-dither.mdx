# Como configurar OrderedDither

Este guia mostra como configurar o componente OrderedDither no objeto POST PROCESSING. Siga os passos abaixo e ajuste as configurações para obter o resultado desejado na cena.

## Passos

1. Selecione o objeto POST PROCESSING no painel Objects.

![Selecione o objeto POST PROCESSING no painel Objects.](/img/guides/ordered-dither/01_select-the-post-processing-object-in-the-objects-panel.png)

### Opcional: Adicione o componente OrderedDither

> Use esta seção somente se o componente ainda não estiver listado no painel Properties. Se ele já estiver presente, ignore as ações desta seção e continue com o tutorial principal abaixo.

2.1. Toque em Add Component para adicionar OrderedDither.

![Toque em Add Component para adicionar OrderedDither.](/img/guides/ordered-dither/02_tap-add-component-to-add-ordereddither.png)

2.2. Abra a categoria Render.

![Abra a categoria Render.](/img/guides/ordered-dither/03_open-the-render-category.png)

2.3. Abra a categoria Stylized.

![Abra a categoria Stylized.](/img/guides/ordered-dither/04_open-the-stylized-category.png)

2.4. Selecione o componente OrderedDither.

![Selecione o componente OrderedDither.](/img/guides/ordered-dither/05_select-the-ordereddither-component.png)

**Fim da seção opcional. Continue com o tutorial principal abaixo.**

2. Selecione o componente OrderedDither para visualizar suas configurações.

![Selecione o componente OrderedDither para visualizar suas configurações.](/img/guides/ordered-dither/06_select-the-ordereddither-component-to-view-its-settings.png)

As configurações de 3. OrderedDither estão visíveis em Properties.

![As configurações de OrderedDither estão visíveis em Properties.](/img/guides/ordered-dither/07_ordereddither-settings-are-visible-in-properties.png)

## Resultado

O componente OrderedDither está configurado e suas opções estão visíveis no painel Properties. Você pode ajustar os valores e visualizar o resultado na cena.
