# Como configurar MotionBlur

Este guia mostra como configurar o componente MotionBlur no objeto POST PROCESSING. Siga os passos abaixo e ajuste as configurações para obter o resultado desejado na cena.

## Passos

1. Selecione o objeto POST PROCESSING no painel Objects.

![Selecione o objeto POST PROCESSING no painel Objects.](/img/guides/motion-blur/01_select-the-post-processing-object-in-the-objects-panel.png)

### Opcional: Adicione o componente MotionBlur

> Use esta seção somente se o componente ainda não estiver listado no painel Properties. Se ele já estiver presente, ignore as ações desta seção e continue com o tutorial principal abaixo.

2.1. Toque em Add Component para adicionar MotionBlur.

![Toque em Add Component para adicionar MotionBlur.](/img/guides/motion-blur/02_tap-add-component-to-add-motionblur.png)

2.2. Abra a categoria Render.

![Abra a categoria Render.](/img/guides/motion-blur/03_open-the-render-category.png)

2.3. Abra a categoria Blur.

![Abra a categoria Blur.](/img/guides/motion-blur/04_open-the-blur-category.png)

2.4. Selecione o componente MotionBlur.

![Selecione o componente MotionBlur.](/img/guides/motion-blur/05_select-the-motionblur-component.png)

**Fim da seção opcional. Continue com o tutorial principal abaixo.**

2. Selecione o componente MotionBlur para visualizar suas configurações.

![Selecione o componente MotionBlur para visualizar suas configurações.](/img/guides/motion-blur/06_select-the-motionblur-component-to-view-its-settings.png)

As configurações de 3. MotionBlur estão visíveis em Properties.

![As configurações de MotionBlur estão visíveis em Properties.](/img/guides/motion-blur/07_motionblur-settings-are-visible-in-properties.png)

## Resultado

O componente MotionBlur está configurado e suas opções estão visíveis no painel Properties. Você pode ajustar os valores e visualizar o resultado na cena.
