# Como configurar GodRaysLightShafts

Este guia mostra como configurar o componente GodRaysLightShafts no objeto POST PROCESSING. Siga os passos abaixo e ajuste as configurações para obter o resultado desejado na cena.

## Passos

1. Selecione o objeto POST PROCESSING no painel Objects.

![Selecione o objeto POST PROCESSING no painel Objects.](/img/guides/configure-god-rays-light-shafts/01_select-the-post-processing-object-in-the-objects-panel.png)

### Opcional: Adicione o componente GodRaysLightShafts

> Use esta seção somente se o componente ainda não estiver listado no painel Properties. Se ele já estiver presente, ignore as ações desta seção e continue com o tutorial principal abaixo.

2.1. Toque em Add Component para adicionar GodRaysLightShafts.

![Toque em Add Component para adicionar GodRaysLightShafts.](/img/guides/configure-god-rays-light-shafts/02_tap-add-component-to-add-godrayslightshafts.png)

2.2. Abra a categoria Render.

![Abra a categoria Render.](/img/guides/configure-god-rays-light-shafts/03_open-the-render-category.png)

2.3. Abra a categoria Lighting.

![Abra a categoria Lighting.](/img/guides/configure-god-rays-light-shafts/04_open-the-lighting-category.png)

2.4. Selecione o componente GodRaysLightShafts.

![Selecione o componente GodRaysLightShafts.](/img/guides/configure-god-rays-light-shafts/05_select-the-godrayslightshafts-component.png)

**Fim da seção opcional. Continue com o tutorial principal abaixo.**

2. Selecione o componente GodRaysLightShafts para visualizar suas configurações.

![Selecione o componente GodRaysLightShafts para visualizar suas configurações.](/img/guides/configure-god-rays-light-shafts/06_select-the-godrayslightshafts-component-to-view-its-settings.png)

As configurações de 3. GodRaysLightShafts estão visíveis em Properties.

![As configurações de GodRaysLightShafts estão visíveis em Properties.](/img/guides/configure-god-rays-light-shafts/07_godrayslightshafts-settings-are-visible-in-properties.png)

## Resultado

O componente GodRaysLightShafts está configurado e suas opções estão visíveis no painel Properties. Você pode ajustar os valores e visualizar o resultado na cena.
