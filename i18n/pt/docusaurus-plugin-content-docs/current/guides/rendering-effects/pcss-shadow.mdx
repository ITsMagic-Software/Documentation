# Como configurar PCSSShadow

Este guia mostra como configurar o componente PCSSShadow no objeto POST PROCESSING. Siga os passos abaixo e ajuste as configurações para obter o resultado desejado na cena.

## Passos

1. Selecione o objeto POST PROCESSING no painel Objects.

![Selecione o objeto POST PROCESSING no painel Objects.](/img/guides/pcss-shadow/01_select-the-post-processing-object-in-the-objects-panel.png)

### Opcional: Adicione o componente PCSSShadow

> Use esta seção somente se o componente ainda não estiver listado no painel Properties. Se ele já estiver presente, ignore as ações desta seção e continue com o tutorial principal abaixo.

2.1. Toque em Add Component para adicionar PCSSShadow.

![Toque em Add Component para adicionar PCSSShadow.](/img/guides/pcss-shadow/02_tap-add-component-to-add-pcssshadow.png)

2.2. Abra a categoria Render.

![Abra a categoria Render.](/img/guides/pcss-shadow/03_open-the-render-category.png)

2.3. Abra a categoria Lighting.

![Abra a categoria Lighting.](/img/guides/pcss-shadow/04_open-the-lighting-category.png)

2.4. Selecione o componente PCSSShadow.

![Selecione o componente PCSSShadow.](/img/guides/pcss-shadow/05_select-the-pcssshadow-component.png)

**Fim da seção opcional. Continue com o tutorial principal abaixo.**

2. Selecione o componente PCSSShadow para visualizar suas configurações.

![Selecione o componente PCSSShadow para visualizar suas configurações.](/img/guides/pcss-shadow/06_select-the-pcssshadow-component-to-view-its-settings.png)

As configurações de 3. PCSSShadow estão visíveis em Properties.

![As configurações de PCSSShadow estão visíveis em Properties.](/img/guides/pcss-shadow/07_pcssshadow-settings-are-visible-in-properties.png)

## Resultado

O componente PCSSShadow está configurado e suas opções estão visíveis no painel Properties. Você pode ajustar os valores e visualizar o resultado na cena.
