# Como configurar FastBloom

Este guia mostra como configurar o componente FastBloom no objeto POST PROCESSING. Siga os passos abaixo e ajuste as configurações para obter o resultado desejado na cena.

## Passos

1. Selecione o objeto POST PROCESSING no painel Objects.

![Selecione o objeto POST PROCESSING no painel Objects.](/img/guides/configure-fast-bloom/01_select-the-post-processing-object-in-the-objects-panel.png)

### Opcional: Adicione o componente FastBloom

> Use esta seção somente se o componente ainda não estiver listado no painel Properties. Se ele já estiver presente, ignore as ações desta seção e continue com o tutorial principal abaixo.

2.1. Toque em Add Component para adicionar FastBloom.

![Toque em Add Component para adicionar FastBloom.](/img/guides/configure-fast-bloom/02_tap-add-component-to-add-fastbloom.png)

2.2. Abra a categoria Render.

![Abra a categoria Render.](/img/guides/configure-fast-bloom/03_open-the-render-category.png)

2.3. Abra a categoria Highlights.

![Abra a categoria Highlights.](/img/guides/configure-fast-bloom/04_open-the-highlights-category.png)

2.4. Selecione o componente FastBloom.

![Selecione o componente FastBloom.](/img/guides/configure-fast-bloom/05_select-the-fastbloom-component.png)

**Fim da seção opcional. Continue com o tutorial principal abaixo.**

2. Selecione o componente FastBloom para visualizar suas configurações.

![Selecione o componente FastBloom para visualizar suas configurações.](/img/guides/configure-fast-bloom/06_select-the-fastbloom-component-to-view-its-settings.png)

As configurações de 3. FastBloom estão visíveis em Properties.

![As configurações de FastBloom estão visíveis em Properties.](/img/guides/configure-fast-bloom/07_fastbloom-settings-are-visible-in-properties.png)

## Resultado

O componente FastBloom está configurado e suas opções estão visíveis no painel Properties. Você pode ajustar os valores e visualizar o resultado na cena.
