# Como configurar Chromatic Aberration

Este guia mostra como configurar o componente Chromatic Aberration no objeto POST PROCESSING. Siga os passos abaixo e ajuste as configurações para obter o resultado desejado na cena.

## Passos

1. Selecione o objeto POST PROCESSING no painel Objects.

![Selecione o objeto POST PROCESSING no painel Objects.](/img/guides/configure-chromatic-aberration/01_select-the-post-processing-object-in-the-objects-panel.png)

### Opcional: Adicione o componente ChromaticAberration

> Use esta seção somente se o componente ainda não estiver listado no painel Properties. Se ele já estiver presente, ignore as ações desta seção e continue com o tutorial principal abaixo.

2.1. Toque em Add Component para adicionar Chromatic Aberration.

![Toque em Add Component para adicionar Chromatic Aberration.](/img/guides/configure-chromatic-aberration/02_tap-add-component-to-add-chromatic-aberration.png)

2.2. Abra a categoria Render.

![Abra a categoria Render.](/img/guides/configure-chromatic-aberration/03_open-the-render-category.png)

2.3. Abra a categoria Lens.

![Abra a categoria Lens.](/img/guides/configure-chromatic-aberration/04_open-the-lens-category.png)

2.4. Selecione o componente Chromatic Aberration.

![Selecione o componente Chromatic Aberration.](/img/guides/configure-chromatic-aberration/05_select-the-chromatic-aberration-component.png)

**Fim da seção opcional. Continue com o tutorial principal abaixo.**

2. Selecione o componente Chromatic Aberration para visualizar suas configurações.

![Selecione o componente Chromatic Aberration para visualizar suas configurações.](/img/guides/configure-chromatic-aberration/06_select-the-chromatic-aberration-component-to-view-its-settings.png)

As configurações de 3. Chromatic Aberration estão visíveis em Properties.

![As configurações de Chromatic Aberration estão visíveis em Properties.](/img/guides/configure-chromatic-aberration/07_chromatic-aberration-settings-are-visible-in-properties.png)

## Resultado

O componente Chromatic Aberration está configurado e suas opções estão visíveis no painel Properties. Você pode ajustar os valores e visualizar o resultado na cena.
