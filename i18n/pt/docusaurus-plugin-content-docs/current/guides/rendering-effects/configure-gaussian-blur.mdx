# Como configurar GaussianBlur

Este guia mostra como configurar o componente GaussianBlur no objeto POST PROCESSING. Siga os passos abaixo e ajuste as configurações para obter o resultado desejado na cena.

## Passos

1. Selecione o objeto POST PROCESSING no painel Objects.

![Selecione o objeto POST PROCESSING no painel Objects.](/img/guides/configure-gaussian-blur/01_select-the-post-processing-object-in-the-objects-panel.png)

### Opcional: Adicione o componente GaussianBlur

> Use esta seção somente se o componente ainda não estiver listado no painel Properties. Se ele já estiver presente, ignore as ações desta seção e continue com o tutorial principal abaixo.

2.1. Toque em Add Component para adicionar GaussianBlur.

![Toque em Add Component para adicionar GaussianBlur.](/img/guides/configure-gaussian-blur/02_tap-add-component-to-add-gaussianblur.png)

2.2. Abra a categoria Render.

![Abra a categoria Render.](/img/guides/configure-gaussian-blur/03_open-the-render-category.png)

2.3. Abra a categoria Blur.

![Abra a categoria Blur.](/img/guides/configure-gaussian-blur/04_open-the-blur-category.png)

2.4. Selecione o componente GaussianBlur.

![Selecione o componente GaussianBlur.](/img/guides/configure-gaussian-blur/05_select-the-gaussianblur-component.png)

**Fim da seção opcional. Continue com o tutorial principal abaixo.**

2. Selecione o componente GaussianBlur para visualizar suas configurações.

![Selecione o componente GaussianBlur para visualizar suas configurações.](/img/guides/configure-gaussian-blur/06_select-the-gaussianblur-component-to-view-its-settings.png)

As configurações de 3. GaussianBlur estão visíveis em Properties.

![As configurações de GaussianBlur estão visíveis em Properties.](/img/guides/configure-gaussian-blur/07_gaussianblur-settings-are-visible-in-properties.png)

## Resultado

O componente GaussianBlur está configurado e suas opções estão visíveis no painel Properties. Você pode ajustar os valores e visualizar o resultado na cena.
