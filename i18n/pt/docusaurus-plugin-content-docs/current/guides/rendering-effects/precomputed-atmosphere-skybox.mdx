# Como configurar PrecomputedAtmosphereSkybox

Este guia mostra como configurar o componente PrecomputedAtmosphereSkybox no objeto POST PROCESSING. Siga os passos abaixo e ajuste as configurações para obter o resultado desejado na cena.

## Passos

1. Selecione o objeto POST PROCESSING no painel Objects.

![Selecione o objeto POST PROCESSING no painel Objects.](/img/guides/precomputed-atmosphere-skybox/01_select-the-post-processing-object-in-the-objects-panel.png)

### Opcional: Adicione o componente PrecomputedAtmosphereSkybox

> Use esta seção somente se o componente ainda não estiver listado no painel Properties. Se ele já estiver presente, ignore as ações desta seção e continue com o tutorial principal abaixo.

2.1. Toque em Add Component para adicionar PrecomputedAtmosphereSkybox.

![Toque em Add Component para adicionar PrecomputedAtmosphereSkybox.](/img/guides/precomputed-atmosphere-skybox/02_tap-add-component-to-add-precomputedatmosphereskybox.png)

2.2. Abra a categoria Render.

![Abra a categoria Render.](/img/guides/precomputed-atmosphere-skybox/03_open-the-render-category.png)

2.3. Abra a categoria Skybox.

![Abra a categoria Skybox.](/img/guides/precomputed-atmosphere-skybox/04_open-the-skybox-category.png)

2.4. Selecione o componente PrecomputedAtmosphereSkybox.

![Selecione o componente PrecomputedAtmosphereSkybox.](/img/guides/precomputed-atmosphere-skybox/05_select-the-precomputedatmosphereskybox-component.png)

**Fim da seção opcional. Continue com o tutorial principal abaixo.**

2. Selecione o componente PrecomputedAtmosphereSkybox para visualizar suas configurações.

![Selecione o componente PrecomputedAtmosphereSkybox para visualizar suas configurações.](/img/guides/precomputed-atmosphere-skybox/06_select-the-precomputedatmosphereskybox-component-to-view-its-settings.png)

As configurações de 3. PrecomputedAtmosphereSkybox estão visíveis em Properties.

![As configurações de PrecomputedAtmosphereSkybox estão visíveis em Properties.](/img/guides/precomputed-atmosphere-skybox/07_precomputedatmosphereskybox-settings-are-visible-in-properties.png)

## Resultado

O componente PrecomputedAtmosphereSkybox está configurado e suas opções estão visíveis no painel Properties. Você pode ajustar os valores e visualizar o resultado na cena.
