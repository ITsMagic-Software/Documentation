# Como configurar PrecomputedAtmosphereSkybox2

Este guia mostra como configurar o componente PrecomputedAtmosphereSkybox2 no objeto POST PROCESSING. Siga os passos abaixo e ajuste as configurações para obter o resultado desejado na cena.

## Passos

1. Selecione o objeto POST PROCESSING no painel Objects.

![Selecione o objeto POST PROCESSING no painel Objects.](/img/guides/precomputed-atmosphere-skybox2/01_select-the-post-processing-object-in-the-objects-panel.png)

### Opcional: Adicione o componente PrecomputedAtmosphereSkybox2

> Use esta seção somente se o componente ainda não estiver listado no painel Properties. Se ele já estiver presente, ignore as ações desta seção e continue com o tutorial principal abaixo.

2.1. Toque em Add Component para adicionar PrecomputedAtmosphereSkybox2.

![Toque em Add Component para adicionar PrecomputedAtmosphereSkybox2.](/img/guides/precomputed-atmosphere-skybox2/02_tap-add-component-to-add-precomputedatmosphereskybox2.png)

2.2. Abra a categoria Render.

![Abra a categoria Render.](/img/guides/precomputed-atmosphere-skybox2/03_open-the-render-category.png)

2.3. Abra a categoria Skybox.

![Abra a categoria Skybox.](/img/guides/precomputed-atmosphere-skybox2/04_open-the-skybox-category.png)

2.4. Selecione o componente PrecomputedAtmosphereSkybox2.

![Selecione o componente PrecomputedAtmosphereSkybox2.](/img/guides/precomputed-atmosphere-skybox2/05_select-the-precomputedatmosphereskybox2-component.png)

**Fim da seção opcional. Continue com o tutorial principal abaixo.**

2. Selecione o componente PrecomputedAtmosphereSkybox2 para visualizar suas configurações.

![Selecione o componente PrecomputedAtmosphereSkybox2 para visualizar suas configurações.](/img/guides/precomputed-atmosphere-skybox2/06_select-the-precomputedatmosphereskybox2-component-to-view-its-settings.png)

As configurações de 3. PrecomputedAtmosphereSkybox2 estão visíveis em Properties.

![As configurações de PrecomputedAtmosphereSkybox2 estão visíveis em Properties.](/img/guides/precomputed-atmosphere-skybox2/07_precomputedatmosphereskybox2-settings-are-visible-in-properties.png)

## Resultado

O componente PrecomputedAtmosphereSkybox2 está configurado e suas opções estão visíveis no painel Properties. Você pode ajustar os valores e visualizar o resultado na cena.
