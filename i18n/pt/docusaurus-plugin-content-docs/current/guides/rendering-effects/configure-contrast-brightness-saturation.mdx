# Como configurar Contrast/Brightness/Saturation

Este guia mostra como configurar o componente Contrast/Brightness/Saturation no objeto POST PROCESSING. Siga os passos abaixo e ajuste as configurações para obter o resultado desejado na cena.

## Passos

1. Selecione o objeto POST PROCESSING no painel Objects.

![Selecione o objeto POST PROCESSING no painel Objects.](/img/guides/configure-contrast-brightness-saturation/01_select-the-post-processing-object-in-the-objects-panel.png)

### Opcional: Adicione o componente ContrastBrightnessSaturation

> Use esta seção somente se o componente ainda não estiver listado no painel Properties. Se ele já estiver presente, ignore as ações desta seção e continue com o tutorial principal abaixo.

2.1. Toque em Add Component para adicionar Contrast/Brightness/Saturation.

![Toque em Add Component para adicionar Contrast/Brightness/Saturation.](/img/guides/configure-contrast-brightness-saturation/02_tap-add-component-to-add-contrast-brightness-saturation.png)

2.2. Abra a categoria Render.

![Abra a categoria Render.](/img/guides/configure-contrast-brightness-saturation/03_open-the-render-category.png)

2.3. Abra a categoria Color grading.

![Abra a categoria Color grading.](/img/guides/configure-contrast-brightness-saturation/04_open-the-color-grading-category.png)

2.4. Selecione o componente Contrast/Brightness/Saturation.

![Selecione o componente Contrast/Brightness/Saturation.](/img/guides/configure-contrast-brightness-saturation/05_select-the-contrast-brightness-saturation-component.png)

**Fim da seção opcional. Continue com o tutorial principal abaixo.**

2. Selecione o componente Contrast/Brightness/Saturation para visualizar suas configurações.

![Selecione o componente Contrast/Brightness/Saturation para visualizar suas configurações.](/img/guides/configure-contrast-brightness-saturation/06_select-the-contrast-brightness-saturation-component-to-view-its-settings.png)

As configurações de 3. Contrast/Brightness/Saturation estão visíveis em Properties.

![As configurações de Contrast/Brightness/Saturation estão visíveis em Properties.](/img/guides/configure-contrast-brightness-saturation/07_contrast-brightness-saturation-settings-are-visible-in-properties.png)

## Resultado

O componente Contrast/Brightness/Saturation está configurado e suas opções estão visíveis no painel Properties. Você pode ajustar os valores e visualizar o resultado na cena.
