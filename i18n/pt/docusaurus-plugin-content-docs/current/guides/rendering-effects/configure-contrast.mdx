# Como configurar Contrast

Este guia mostra como configurar o componente Contrast no objeto POST PROCESSING. Siga os passos abaixo e ajuste as configurações para obter o resultado desejado na cena.

## Passos

1. Selecione o objeto POST PROCESSING no painel Objects.

![Selecione o objeto POST PROCESSING no painel Objects.](/img/guides/configure-contrast/01_select-the-post-processing-object-in-the-objects-panel.png)

### Opcional: Adicione o componente Contrast

> Use esta seção somente se o componente ainda não estiver listado no painel Properties. Se ele já estiver presente, ignore as ações desta seção e continue com o tutorial principal abaixo.

2.1. Toque em Add Component para adicionar Contrast.

![Toque em Add Component para adicionar Contrast.](/img/guides/configure-contrast/02_tap-add-component-to-add-contrast.png)

2.2. Abra a categoria Render.

![Abra a categoria Render.](/img/guides/configure-contrast/03_open-the-render-category.png)

2.3. Abra a categoria Color grading.

![Abra a categoria Color grading.](/img/guides/configure-contrast/04_open-the-color-grading-category.png)

2.4. Selecione o componente Contrast.

![Selecione o componente Contrast.](/img/guides/configure-contrast/05_select-the-contrast-component.png)

**Fim da seção opcional. Continue com o tutorial principal abaixo.**

2. Selecione o componente Contrast para visualizar suas configurações.

![Selecione o componente Contrast para visualizar suas configurações.](/img/guides/configure-contrast/06_select-the-contrast-component-to-view-its-settings.png)

As configurações de 3. Contrast estão visíveis em Properties.

![As configurações de Contrast estão visíveis em Properties.](/img/guides/configure-contrast/07_contrast-settings-are-visible-in-properties.png)

## Resultado

O componente Contrast está configurado e suas opções estão visíveis no painel Properties. Você pode ajustar os valores e visualizar o resultado na cena.
