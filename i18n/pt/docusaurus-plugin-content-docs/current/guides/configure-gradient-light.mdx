# Como configurar GradientLight

Este guia mostra como configurar o componente GradientLight no objeto POST PROCESSING. Siga os passos abaixo e ajuste as configurações para obter o resultado desejado na cena.

## Passos

1. Selecione o objeto POST PROCESSING no painel Objects.

![Selecione o objeto POST PROCESSING no painel Objects.](/img/guides/configure-gradient-light/01_select-the-post-processing-object-in-the-objects-panel.png)

### Opcional: Adicione o componente GradientLight

> Use esta seção somente se o componente ainda não estiver listado no painel Properties. Se ele já estiver presente, ignore as ações desta seção e continue com o tutorial principal abaixo.

2.1. Toque em Add Component para adicionar GradientLight.

![Toque em Add Component para adicionar GradientLight.](/img/guides/configure-gradient-light/02_tap-add-component-to-add-gradientlight.png)

2.2. Abra a categoria Render.

![Abra a categoria Render.](/img/guides/configure-gradient-light/03_open-the-render-category.png)

2.3. Abra a categoria Light.

![Abra a categoria Light.](/img/guides/configure-gradient-light/04_open-the-light-category.png)

2.4. Selecione o componente GradientLight.

![Selecione o componente GradientLight.](/img/guides/configure-gradient-light/05_select-the-gradientlight-component.png)

**Fim da seção opcional. Continue com o tutorial principal abaixo.**

2. Selecione o componente GradientLight para visualizar suas configurações.

![Selecione o componente GradientLight para visualizar suas configurações.](/img/guides/configure-gradient-light/06_select-the-gradientlight-component-to-view-its-settings.png)

As configurações de 3. GradientLight estão visíveis em Properties.

![As configurações de GradientLight estão visíveis em Properties.](/img/guides/configure-gradient-light/07_gradientlight-settings-are-visible-in-properties.png)

## Resultado

O componente GradientLight está configurado e suas opções estão visíveis no painel Properties. Você pode ajustar os valores e visualizar o resultado na cena.
