# Como configurar VSMShadow

Este guia mostra como configurar o componente VSMShadow no objeto POST PROCESSING. Siga os passos abaixo e ajuste as configurações para obter o resultado desejado na cena.

## Passos

1. Selecione o objeto POST PROCESSING no painel Objects.

![Selecione o objeto POST PROCESSING no painel Objects.](/img/guides/vsm-shadow/01_select-the-post-processing-object-in-the-objects-panel.png)

### Opcional: Adicione o componente VSMShadow

> Use esta seção somente se o componente ainda não estiver listado no painel Properties. Se ele já estiver presente, ignore as ações desta seção e continue com o tutorial principal abaixo.

2.1. Toque em Add Component para adicionar VSMShadow.

![Toque em Add Component para adicionar VSMShadow.](/img/guides/vsm-shadow/02_tap-add-component-to-add-vsmshadow.png)

2.2. Abra a categoria Render.

![Abra a categoria Render.](/img/guides/vsm-shadow/03_open-the-render-category.png)

2.3. Abra a categoria Lighting.

![Abra a categoria Lighting.](/img/guides/vsm-shadow/04_open-the-lighting-category.png)

2.4. Selecione o componente VSMShadow.

![Selecione o componente VSMShadow.](/img/guides/vsm-shadow/05_select-the-vsmshadow-component.png)

**Fim da seção opcional. Continue com o tutorial principal abaixo.**

2. Selecione o componente VSMShadow para visualizar suas configurações.

![Selecione o componente VSMShadow para visualizar suas configurações.](/img/guides/vsm-shadow/06_select-the-vsmshadow-component-to-view-its-settings.png)

As configurações de 3. VSMShadow estão visíveis em Properties.

![As configurações de VSMShadow estão visíveis em Properties.](/img/guides/vsm-shadow/07_vsmshadow-settings-are-visible-in-properties.png)

## Resultado

O componente VSMShadow está configurado e suas opções estão visíveis no painel Properties. Você pode ajustar os valores e visualizar o resultado na cena.
