# Como configurar Halftone

Este guia mostra como configurar o componente Halftone no objeto POST PROCESSING. Siga os passos abaixo e ajuste as configurações para obter o resultado desejado na cena.

## Passos

1. Selecione o objeto POST PROCESSING no painel Objects.

![Selecione o objeto POST PROCESSING no painel Objects.](/img/guides/configure-halftone/01_select-the-post-processing-object-in-the-objects-panel.png)

### Opcional: Adicione o componente Halftone

> Use esta seção somente se o componente ainda não estiver listado no painel Properties. Se ele já estiver presente, ignore as ações desta seção e continue com o tutorial principal abaixo.

2.1. Toque em Add Component para adicionar Halftone.

![Toque em Add Component para adicionar Halftone.](/img/guides/configure-halftone/02_tap-add-component-to-add-halftone.png)

2.2. Abra a categoria Render.

![Abra a categoria Render.](/img/guides/configure-halftone/03_open-the-render-category.png)

2.3. Abra a categoria Stylized.

![Abra a categoria Stylized.](/img/guides/configure-halftone/04_open-the-stylized-category.png)

2.4. Selecione o componente Halftone.

![Selecione o componente Halftone.](/img/guides/configure-halftone/05_select-the-halftone-component.png)

**Fim da seção opcional. Continue com o tutorial principal abaixo.**

2. Selecione o componente Halftone para visualizar suas configurações.

![Selecione o componente Halftone para visualizar suas configurações.](/img/guides/configure-halftone/06_select-the-halftone-component-to-view-its-settings.png)

As configurações de 3. Halftone estão visíveis em Properties.

![As configurações de Halftone estão visíveis em Properties.](/img/guides/configure-halftone/07_halftone-settings-are-visible-in-properties.png)

## Resultado

O componente Halftone está configurado e suas opções estão visíveis no painel Properties. Você pode ajustar os valores e visualizar o resultado na cena.
