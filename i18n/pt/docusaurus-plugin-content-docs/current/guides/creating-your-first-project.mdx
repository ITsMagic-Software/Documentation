# Criando seu primeiro projeto

Este guia mostra como criar um projeto vazio no ITsMagic. Um projeto vazio é um bom ponto de partida quando você quer construir tudo por conta própria.

## Passos

### 1. Abra o menu de projetos

Na tela inicial do ITsMagic, toque em **New project**.

![Toque em New project.](/img/guides/create-empty-project/01_tap-new-project.png)

### 2. Escolha um projeto vazio

Na parte superior da tela de seleção de templates, toque em **New empty project**. Essa opção cria um projeto sem um template pré-configurado.

![Toque em New empty project.](/img/guides/create-empty-project/02_tap-new-empty-project-at-the-top-of-the-template-selection-screen.png)

### 3. Dê um nome ao projeto

Digite um nome curto e fácil de reconhecer em **Project title**. Escolha um nome que ajude você a encontrar o projeto depois.

![Escolha um nome para o projeto.](/img/guides/create-empty-project/03_choose-a-clear-name-for-your-project-so-you-can-find-it-easily-later.png)

### 4. Crie o projeto

Toque em **Confirm**. O ITsMagic criará o projeto vazio e o abrirá no editor.

![Toque em Confirm.](/img/guides/create-empty-project/04_tap-confirm-to-create-the-project.png)

Agora você pode começar a adicionar cenas, objetos, componentes e scripts ao projeto.
