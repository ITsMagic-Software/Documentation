# Como criar um projeto a partir de um template

Templates oferecem um ponto de partida pronto. Neste guia, você criará um projeto usando o template **Double hitch pickup**. Depois de criar o projeto, você poderá alterar os recursos e a configuração inicial do template.

## Passos

### 1. Abra o menu de projetos

Na tela inicial do ITsMagic, toque em **New project**.

![Toque em New project.](/img/guides/create-double-hitch-pickup-project/01_tap-new-project.png)

### 2. Selecione o template

Encontre e selecione **Double hitch pickup** na lista de templates. Ao selecioná-lo, você define esse template como ponto de partida do projeto.

![Selecione o template Double hitch pickup.](/img/guides/create-double-hitch-pickup-project/02_select-the-double-hitch-pickup-template.png)

### 3. Comece a partir do template

Toque em **Create project** para usar o template selecionado.

![Toque em Create project.](/img/guides/create-double-hitch-pickup-project/03_tap-create-project-to-use-this-template-as-your-starting-point.png)

### 4. Dê um nome ao projeto

Digite um nome curto e fácil de reconhecer em **Project title**. Use um nome que descreva o seu projeto, em vez de depender do nome do template.

![Escolha um nome para o projeto.](/img/guides/create-double-hitch-pickup-project/04_choose-a-clear-name-for-your-project-so-you-can-find-it-easily-later.png)

### 5. Crie o projeto

Toque em **Confirm**. O ITsMagic criará o projeto com os recursos e a configuração inicial do template.

![Toque em Confirm.](/img/guides/create-double-hitch-pickup-project/05_tap-confirm-to-create-your-project-from-the-template.png)

Agora você pode explorar o template, substituir seu conteúdo e adaptá-lo ao seu próprio jogo.
