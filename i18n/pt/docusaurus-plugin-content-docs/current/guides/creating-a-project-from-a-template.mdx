# Como criar um projeto a partir de um template

Templates oferecem um ponto de partida pronto. Neste guia, o template **Double hitch pickup** é usado como exemplo, mas você pode escolher qualquer template que preferir. Depois de criar o projeto, você poderá alterar os recursos e a configuração inicial do template.

## Passos

### 1. Abra o menu de projetos

Na tela inicial do ITsMagic, toque em **New project**.

![Toque em New project.](/img/guides/create-double-hitch-pickup-project/01_tap-new-project.png)

### 2. Selecione um template

Selecione qualquer template que você queira usar. Nesta demonstração, o **Double hitch pickup** é usado como exemplo.

![Selecione um template.](/img/guides/create-double-hitch-pickup-project/02_select-any-template-you-would-like-to-use-this-demonstration-uses-double-hitch-pickup.png)

### 3. Comece a partir do template

Toque em **Create project** para usar o template selecionado.

![Toque em Create project.](/img/guides/create-double-hitch-pickup-project/03_tap-create-project-to-use-this-template-as-your-starting-point.png)

### 4. Dê um nome ao projeto

Digite um nome curto e fácil de reconhecer em **Project title**. Use um nome que descreva o seu projeto, em vez de depender do nome do template.

![Escolha um nome para o projeto.](/img/guides/create-double-hitch-pickup-project/04_choose-a-clear-name-for-your-project-so-you-can-find-it-easily-later.png)

### 5. Crie o projeto

Toque em **Confirm**. O ITsMagic criará o projeto com os recursos e a configuração inicial do template.

![Toque em Confirm.](/img/guides/create-double-hitch-pickup-project/05_tap-confirm-to-create-your-project-from-the-template.png)

### 6. Aguarde enquanto o projeto é aberto

Agora o ITsMagic abrirá e construirá o projeto. Aguarde até que a tela de abertura termine antes de continuar.

![Aguarde enquanto o projeto é aberto e construído.](/img/guides/create-double-hitch-pickup-project/06_the-project-is-opening-and-being-built-please-wait-for-this-opening-screen-to-finish.png)

### 7. Comece a trabalhar no editor

Quando o novo projeto terminar de carregar, ele será aberto no editor. Agora você pode explorar o template, substituir seu conteúdo e adaptá-lo ao seu próprio jogo.

![O novo projeto está aberto no editor.](/img/guides/create-double-hitch-pickup-project/07_the-new-project-has-finished-loading-and-is-open-in-the-editor.png)
