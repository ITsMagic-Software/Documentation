# Como configurar Saturation

Este guia mostra como configurar o componente Saturation no objeto POST PROCESSING. Siga os passos abaixo e ajuste as configurações para obter o resultado desejado na cena.

## Passos

1. Selecione o objeto POST PROCESSING no painel Objects.

![Selecione o objeto POST PROCESSING no painel Objects.](/img/guides/saturation/01_select-the-post-processing-object-in-the-objects-panel.png)

### Opcional: Adicione o componente Saturation

> Use esta seção somente se o componente ainda não estiver listado no painel Properties. Se ele já estiver presente, ignore as ações desta seção e continue com o tutorial principal abaixo.

2.1. Toque em Add Component para adicionar Saturation.

![Toque em Add Component para adicionar Saturation.](/img/guides/saturation/02_tap-add-component-to-add-saturation.png)

2.2. Abra a categoria Render.

![Abra a categoria Render.](/img/guides/saturation/03_open-the-render-category.png)

2.3. Abra a categoria Color grading.

![Abra a categoria Color grading.](/img/guides/saturation/04_open-the-color-grading-category.png)

2.4. Selecione o componente Saturation.

![Selecione o componente Saturation.](/img/guides/saturation/05_select-the-saturation-component.png)

**Fim da seção opcional. Continue com o tutorial principal abaixo.**

2. Selecione o componente Saturation para visualizar suas configurações.

![Selecione o componente Saturation para visualizar suas configurações.](/img/guides/saturation/06_select-the-saturation-component-to-view-its-settings.png)

As configurações de 3. Saturation estão visíveis em Properties.

![As configurações de Saturation estão visíveis em Properties.](/img/guides/saturation/07_saturation-settings-are-visible-in-properties.png)

## Resultado

O componente Saturation está configurado e suas opções estão visíveis no painel Properties. Você pode ajustar os valores e visualizar o resultado na cena.
