# Como configurar LensDirt

Este guia mostra como configurar o componente LensDirt no objeto POST PROCESSING. Siga os passos abaixo e ajuste as configurações para obter o resultado desejado na cena.

## Passos

1. Selecione o objeto POST PROCESSING no painel Objects.

![Selecione o objeto POST PROCESSING no painel Objects.](/img/guides/configure-lens-dirt/01_select-the-post-processing-object-in-the-objects-panel.png)

### Opcional: Adicione o componente LensDirt

> Use esta seção somente se o componente ainda não estiver listado no painel Properties. Se ele já estiver presente, ignore as ações desta seção e continue com o tutorial principal abaixo.

2.1. Toque em Add Component para adicionar LensDirt.

![Toque em Add Component para adicionar LensDirt.](/img/guides/configure-lens-dirt/02_tap-add-component-to-add-lensdirt.png)

2.2. Abra a categoria Render.

![Abra a categoria Render.](/img/guides/configure-lens-dirt/03_open-the-render-category.png)

2.3. Abra a categoria Lens.

![Abra a categoria Lens.](/img/guides/configure-lens-dirt/04_open-the-lens-category.png)

2.4. Selecione o componente LensDirt.

![Selecione o componente LensDirt.](/img/guides/configure-lens-dirt/05_select-the-lensdirt-component.png)

**Fim da seção opcional. Continue com o tutorial principal abaixo.**

2. Selecione o componente LensDirt para visualizar suas configurações.

![Selecione o componente LensDirt para visualizar suas configurações.](/img/guides/configure-lens-dirt/06_select-the-lensdirt-component-to-view-its-settings.png)

As configurações de 3. LensDirt estão visíveis em Properties.

![As configurações de LensDirt estão visíveis em Properties.](/img/guides/configure-lens-dirt/07_lensdirt-settings-are-visible-in-properties.png)

## Resultado

O componente LensDirt está configurado e suas opções estão visíveis no painel Properties. Você pode ajustar os valores e visualizar o resultado na cena.
