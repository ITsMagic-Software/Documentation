# Como configurar Fog

Este guia mostra como configurar o componente Fog no objeto POST PROCESSING. Siga os passos abaixo e ajuste as configurações para obter o resultado desejado na cena.

## Passos

1. Selecione o objeto POST PROCESSING no painel Objects.

![Selecione o objeto POST PROCESSING no painel Objects.](/img/guides/configure-fog/01_select-the-post-processing-object-in-the-objects-panel.png)

### Opcional: Adicione o componente Fog

> Use esta seção somente se o componente ainda não estiver listado no painel Properties. Se ele já estiver presente, ignore as ações desta seção e continue com o tutorial principal abaixo.

2.1. Toque em Add Component para adicionar Fog.

![Toque em Add Component para adicionar Fog.](/img/guides/configure-fog/02_tap-add-component-to-add-fog.png)

2.2. Abra a categoria Render.

![Abra a categoria Render.](/img/guides/configure-fog/03_open-the-render-category.png)

2.3. Abra a categoria Volumetric.

![Abra a categoria Volumetric.](/img/guides/configure-fog/04_open-the-volumetric-category.png)

2.4. Selecione o componente Fog.

![Selecione o componente Fog.](/img/guides/configure-fog/05_select-the-fog-component.png)

**Fim da seção opcional. Continue com o tutorial principal abaixo.**

2. Selecione o componente Fog para visualizar suas configurações.

![Selecione o componente Fog para visualizar suas configurações.](/img/guides/configure-fog/06_select-the-fog-component-to-view-its-settings.png)

As configurações de 3. Fog estão visíveis em Properties.

![As configurações de Fog estão visíveis em Properties.](/img/guides/configure-fog/07_fog-settings-are-visible-in-properties.png)

## Resultado

O componente Fog está configurado e suas opções estão visíveis no painel Properties. Você pode ajustar os valores e visualizar o resultado na cena.
