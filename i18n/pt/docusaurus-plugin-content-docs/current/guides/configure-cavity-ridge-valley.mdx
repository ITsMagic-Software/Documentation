# Como configurar CavityRidgeValley

Este guia mostra como configurar o componente CavityRidgeValley no objeto POST PROCESSING. Siga os passos abaixo e ajuste as configurações para obter o resultado desejado na cena.

## Passos

1. Selecione o objeto POST PROCESSING no painel Objects.

![Selecione o objeto POST PROCESSING no painel Objects.](/img/guides/configure-cavity-ridge-valley/01_select-the-post-processing-object-in-the-objects-panel.png)

### Opcional: Adicione o componente CavityRidgeValley

> Use esta seção somente se o componente ainda não estiver listado no painel Properties. Se ele já estiver presente, ignore as ações desta seção e continue com o tutorial principal abaixo.

2.1. Toque em Add Component para adicionar CavityRidgeValley.

![Toque em Add Component para adicionar CavityRidgeValley.](/img/guides/configure-cavity-ridge-valley/02_tap-add-component-to-add-cavityridgevalley.png)

2.2. Abra a categoria Render.

![Abra a categoria Render.](/img/guides/configure-cavity-ridge-valley/03_open-the-render-category.png)

2.3. Abra a categoria Highlights.

![Abra a categoria Highlights.](/img/guides/configure-cavity-ridge-valley/04_open-the-highlights-category.png)

2.4. Selecione o componente CavityRidgeValley.

![Selecione o componente CavityRidgeValley.](/img/guides/configure-cavity-ridge-valley/05_select-the-cavityridgevalley-component.png)

**Fim da seção opcional. Continue com o tutorial principal abaixo.**

2. Selecione o componente Cavity Ridge/Valley para visualizar suas configurações.

![Selecione o componente Cavity Ridge/Valley para visualizar suas configurações.](/img/guides/configure-cavity-ridge-valley/06_select-the-cavity-ridge-valley-component-to-view-its-settings.png)

As configurações de 3. Cavity Ridge/Valley estão visíveis no painel Properties.

![As configurações de Cavity Ridge/Valley estão visíveis no painel Properties.](/img/guides/configure-cavity-ridge-valley/07_cavity-ridge-valley-settings-are-visible-in-the-properties-panel.png)

## Resultado

O componente CavityRidgeValley está configurado e suas opções estão visíveis no painel Properties. Você pode ajustar os valores e visualizar o resultado na cena.
