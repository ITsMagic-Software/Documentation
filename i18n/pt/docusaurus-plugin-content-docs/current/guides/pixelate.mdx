# Como configurar Pixelate

Este guia mostra como configurar o componente Pixelate no objeto POST PROCESSING. Siga os passos abaixo e ajuste as configurações para obter o resultado desejado na cena.

## Passos

1. Selecione o objeto POST PROCESSING no painel Objects.

![Selecione o objeto POST PROCESSING no painel Objects.](/img/guides/pixelate/01_select-the-post-processing-object-in-the-objects-panel.png)

### Opcional: Adicione o componente Pixelate

> Use esta seção somente se o componente ainda não estiver listado no painel Properties. Se ele já estiver presente, ignore as ações desta seção e continue com o tutorial principal abaixo.

2.1. Toque em Add Component para adicionar Pixelate.

![Toque em Add Component para adicionar Pixelate.](/img/guides/pixelate/02_tap-add-component-to-add-pixelate.png)

2.2. Abra a categoria Render.

![Abra a categoria Render.](/img/guides/pixelate/03_open-the-render-category.png)

2.3. Abra a categoria Stylized.

![Abra a categoria Stylized.](/img/guides/pixelate/04_open-the-stylized-category.png)

2.4. Selecione o componente Pixelate.

![Selecione o componente Pixelate.](/img/guides/pixelate/05_select-the-pixelate-component.png)

**Fim da seção opcional. Continue com o tutorial principal abaixo.**

2. Selecione o componente Pixelate para visualizar suas configurações.

![Selecione o componente Pixelate para visualizar suas configurações.](/img/guides/pixelate/06_select-the-pixelate-component-to-view-its-settings.png)

As configurações de 3. Pixelate estão visíveis em Properties.

![As configurações de Pixelate estão visíveis em Properties.](/img/guides/pixelate/07_pixelate-settings-are-visible-in-properties.png)

## Resultado

O componente Pixelate está configurado e suas opções estão visíveis no painel Properties. Você pode ajustar os valores e visualizar o resultado na cena.
