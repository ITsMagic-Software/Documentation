# Como configurar PostVignette

Este guia mostra como configurar o componente PostVignette no objeto POST PROCESSING. Siga os passos abaixo e ajuste as configurações para obter o resultado desejado na cena.

## Passos

1. Selecione o objeto POST PROCESSING no painel Objects.

![Selecione o objeto POST PROCESSING no painel Objects.](/img/guides/post-vignette/01_select-the-post-processing-object-in-the-objects-panel.png)

### Opcional: Adicione o componente PostVignette

> Use esta seção somente se o componente ainda não estiver listado no painel Properties. Se ele já estiver presente, ignore as ações desta seção e continue com o tutorial principal abaixo.

2.1. Toque em Add Component para adicionar PostVignette.

![Toque em Add Component para adicionar PostVignette.](/img/guides/post-vignette/02_tap-add-component-to-add-postvignette.png)

2.2. Abra a categoria Render.

![Abra a categoria Render.](/img/guides/post-vignette/03_open-the-render-category.png)

2.3. Abra a categoria Lens.

![Abra a categoria Lens.](/img/guides/post-vignette/04_open-the-lens-category.png)

2.4. Selecione o componente PostVignette.

![Selecione o componente PostVignette.](/img/guides/post-vignette/05_select-the-postvignette-component.png)

**Fim da seção opcional. Continue com o tutorial principal abaixo.**

2. Selecione o componente PostVignette para visualizar suas configurações.

![Selecione o componente PostVignette para visualizar suas configurações.](/img/guides/post-vignette/06_select-the-postvignette-component-to-view-its-settings.png)

As configurações de 3. PostVignette estão visíveis em Properties.

![As configurações de PostVignette estão visíveis em Properties.](/img/guides/post-vignette/07_postvignette-settings-are-visible-in-properties.png)

## Resultado

O componente PostVignette está configurado e suas opções estão visíveis no painel Properties. Você pode ajustar os valores e visualizar o resultado na cena.
