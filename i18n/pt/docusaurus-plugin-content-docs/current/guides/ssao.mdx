# Como configurar SSAO

Este guia mostra como configurar o componente SSAO no objeto POST PROCESSING. Siga os passos abaixo e ajuste as configurações para obter o resultado desejado na cena.

## Passos

1. Selecione o objeto POST PROCESSING no painel Objects.

![Selecione o objeto POST PROCESSING no painel Objects.](/img/guides/ssao/01_select-the-post-processing-object-in-the-objects-panel.png)

### Opcional: Adicione o componente SSAO

> Use esta seção somente se o componente ainda não estiver listado no painel Properties. Se ele já estiver presente, ignore as ações desta seção e continue com o tutorial principal abaixo.

**Fim da seção opcional. Continue com o tutorial principal abaixo.**

2. Selecione o componente SSAO para visualizar suas configurações.

![Selecione o componente SSAO para visualizar suas configurações.](/img/guides/ssao/02_select-the-ssao-component-to-view-its-settings.png)

As configurações de 3. SSAO estão visíveis em Properties.

![As configurações de SSAO estão visíveis em Properties.](/img/guides/ssao/03_ssao-settings-are-visible-in-properties.png)

## Resultado

O componente SSAO está configurado e suas opções estão visíveis no painel Properties. Você pode ajustar os valores e visualizar o resultado na cena.
