# Como configurar Sharpen

Este guia mostra como configurar o componente Sharpen no objeto POST PROCESSING. Siga os passos abaixo e ajuste as configurações para obter o resultado desejado na cena.

## Passos

1. Selecione o objeto POST PROCESSING no painel Objects.

![Selecione o objeto POST PROCESSING no painel Objects.](/img/guides/sharpen/01_select-the-post-processing-object-in-the-objects-panel.png)

### Opcional: Adicione o componente Sharpen

> Use esta seção somente se o componente ainda não estiver listado no painel Properties. Se ele já estiver presente, ignore as ações desta seção e continue com o tutorial principal abaixo.

2.1. Toque em Add Component para adicionar Sharpen.

![Toque em Add Component para adicionar Sharpen.](/img/guides/sharpen/02_tap-add-component-to-add-sharpen.png)

2.2. Abra a categoria Render.

![Abra a categoria Render.](/img/guides/sharpen/03_open-the-render-category.png)

2.3. Abra a categoria Highlights.

![Abra a categoria Highlights.](/img/guides/sharpen/04_open-the-highlights-category.png)

2.4. Selecione o componente Sharpen.

![Selecione o componente Sharpen.](/img/guides/sharpen/05_select-the-sharpen-component.png)

**Fim da seção opcional. Continue com o tutorial principal abaixo.**

2. Selecione o componente Sharpen para visualizar suas configurações.

![Selecione o componente Sharpen para visualizar suas configurações.](/img/guides/sharpen/06_select-the-sharpen-component-to-view-its-settings.png)

As configurações de 3. Sharpen estão visíveis em Properties.

![As configurações de Sharpen estão visíveis em Properties.](/img/guides/sharpen/07_sharpen-settings-are-visible-in-properties.png)

## Resultado

O componente Sharpen está configurado e suas opções estão visíveis no painel Properties. Você pode ajustar os valores e visualizar o resultado na cena.
