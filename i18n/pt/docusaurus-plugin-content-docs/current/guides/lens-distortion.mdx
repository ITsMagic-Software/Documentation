# Como configurar LensDistortion

Este guia mostra como configurar o componente LensDistortion no objeto POST PROCESSING. Siga os passos abaixo e ajuste as configurações para obter o resultado desejado na cena.

## Passos

1. Selecione o objeto POST PROCESSING no painel Objects.

![Selecione o objeto POST PROCESSING no painel Objects.](/img/guides/lens-distortion/01_select-the-post-processing-object-in-the-objects-panel.png)

### Opcional: Adicione o componente LensDistortion

> Use esta seção somente se o componente ainda não estiver listado no painel Properties. Se ele já estiver presente, ignore as ações desta seção e continue com o tutorial principal abaixo.

2.1. Toque em Add Component para adicionar LensDistortion.

![Toque em Add Component para adicionar LensDistortion.](/img/guides/lens-distortion/02_tap-add-component-to-add-lensdistortion.png)

2.2. Abra a categoria Render.

![Abra a categoria Render.](/img/guides/lens-distortion/03_open-the-render-category.png)

2.3. Abra a categoria Lens.

![Abra a categoria Lens.](/img/guides/lens-distortion/04_open-the-lens-category.png)

2.4. Selecione o componente LensDistortion.

![Selecione o componente LensDistortion.](/img/guides/lens-distortion/05_select-the-lensdistortion-component.png)

**Fim da seção opcional. Continue com o tutorial principal abaixo.**

2. Selecione o componente LensDistortion para visualizar suas configurações.

![Selecione o componente LensDistortion para visualizar suas configurações.](/img/guides/lens-distortion/06_select-the-lensdistortion-component-to-view-its-settings.png)

As configurações de 3. LensDistortion estão visíveis em Properties.

![As configurações de LensDistortion estão visíveis em Properties.](/img/guides/lens-distortion/07_lensdistortion-settings-are-visible-in-properties.png)

## Resultado

O componente LensDistortion está configurado e suas opções estão visíveis no painel Properties. Você pode ajustar os valores e visualizar o resultado na cena.
