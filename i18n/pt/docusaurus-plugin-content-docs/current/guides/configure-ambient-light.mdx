# Como configurar AmbientLight

Este guia mostra como configurar o componente AmbientLight no objeto POST PROCESSING. Siga os passos abaixo e ajuste as configurações para obter o resultado desejado na cena.

## Passos

1. Selecione o objeto POST PROCESSING no painel Objects.

![Selecione o objeto POST PROCESSING no painel Objects.](/img/guides/configure-ambient-light/01_select-the-post-processing-object-in-the-objects-panel.png)

### Opcional: Adicione o componente AmbientLight

> Use esta seção somente se o componente ainda não estiver listado no painel Properties. Se ele já estiver presente, ignore as ações desta seção e continue com o tutorial principal abaixo.

**Fim da seção opcional. Continue com o tutorial principal abaixo.**

2. Selecione o componente AmbientLight para visualizar suas configurações.

![Selecione o componente AmbientLight para visualizar suas configurações.](/img/guides/configure-ambient-light/02_select-the-ambientlight-component-to-view-its-settings.png)

As configurações de 3. AmbientLight estão visíveis no painel Properties.

![As configurações de AmbientLight estão visíveis no painel Properties.](/img/guides/configure-ambient-light/03_ambientlight-settings-are-visible-in-the-properties-panel.png)

## Resultado

O componente AmbientLight está configurado e suas opções estão visíveis no painel Properties. Você pode ajustar os valores e visualizar o resultado na cena.
