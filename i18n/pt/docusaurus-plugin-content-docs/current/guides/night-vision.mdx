# Como configurar NightVision

Este guia mostra como configurar o componente NightVision no objeto POST PROCESSING. Siga os passos abaixo e ajuste as configurações para obter o resultado desejado na cena.

## Passos

1. Selecione o objeto POST PROCESSING no painel Objects.

![Selecione o objeto POST PROCESSING no painel Objects.](/img/guides/night-vision/01_select-the-post-processing-object-in-the-objects-panel.png)

### Opcional: Adicione o componente NightVision

> Use esta seção somente se o componente ainda não estiver listado no painel Properties. Se ele já estiver presente, ignore as ações desta seção e continue com o tutorial principal abaixo.

2.1. Toque em Add Component para adicionar NightVision.

![Toque em Add Component para adicionar NightVision.](/img/guides/night-vision/02_tap-add-component-to-add-nightvision.png)

2.2. Abra a categoria Render.

![Abra a categoria Render.](/img/guides/night-vision/03_open-the-render-category.png)

2.3. Abra a categoria Film.

![Abra a categoria Film.](/img/guides/night-vision/04_open-the-film-category.png)

2.4. Selecione o componente NightVision.

![Selecione o componente NightVision.](/img/guides/night-vision/05_select-the-nightvision-component.png)

**Fim da seção opcional. Continue com o tutorial principal abaixo.**

2. Selecione o componente NightVision para visualizar suas configurações.

![Selecione o componente NightVision para visualizar suas configurações.](/img/guides/night-vision/06_select-the-nightvision-component-to-view-its-settings.png)

As configurações de 3. NightVision estão visíveis em Properties.

![As configurações de NightVision estão visíveis em Properties.](/img/guides/night-vision/07_nightvision-settings-are-visible-in-properties.png)

## Resultado

O componente NightVision está configurado e suas opções estão visíveis no painel Properties. Você pode ajustar os valores e visualizar o resultado na cena.
