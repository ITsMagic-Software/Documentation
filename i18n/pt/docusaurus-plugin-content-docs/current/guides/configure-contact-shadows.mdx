# Como configurar Contact Shadows

Este guia mostra como configurar o componente Contact Shadows no objeto POST PROCESSING. Siga os passos abaixo e ajuste as configurações para obter o resultado desejado na cena.

## Passos

1. Selecione o objeto POST PROCESSING no painel Objects.

![Selecione o objeto POST PROCESSING no painel Objects.](/img/guides/configure-contact-shadows/01_select-the-post-processing-object-in-the-objects-panel.png)

### Opcional: Adicione o componente ContactShadows

> Use esta seção somente se o componente ainda não estiver listado no painel Properties. Se ele já estiver presente, ignore as ações desta seção e continue com o tutorial principal abaixo.

2.1. Toque em Add Component para adicionar Contact Shadows.

![Toque em Add Component para adicionar Contact Shadows.](/img/guides/configure-contact-shadows/02_tap-add-component-to-add-contact-shadows.png)

2.2. Abra a categoria Render.

![Abra a categoria Render.](/img/guides/configure-contact-shadows/03_open-the-render-category.png)

2.3. Abra a categoria Lighting.

![Abra a categoria Lighting.](/img/guides/configure-contact-shadows/04_open-the-lighting-category.png)

2.4. Selecione o componente Contact Shadows.

![Selecione o componente Contact Shadows.](/img/guides/configure-contact-shadows/05_select-the-contact-shadows-component.png)

**Fim da seção opcional. Continue com o tutorial principal abaixo.**

2. Selecione o componente Contact Shadows para visualizar suas configurações.

![Selecione o componente Contact Shadows para visualizar suas configurações.](/img/guides/configure-contact-shadows/06_select-the-contact-shadows-component-to-view-its-settings.png)

As configurações de 3. Contact Shadows estão visíveis em Properties.

![As configurações de Contact Shadows estão visíveis em Properties.](/img/guides/configure-contact-shadows/07_contact-shadows-settings-are-visible-in-properties.png)

## Resultado

O componente Contact Shadows está configurado e suas opções estão visíveis no painel Properties. Você pode ajustar os valores e visualizar o resultado na cena.
