# Como configurar DepthOfField

Este guia mostra como configurar o componente DepthOfField no objeto POST PROCESSING. Siga os passos abaixo e ajuste as configurações para obter o resultado desejado na cena.

## Passos

1. Selecione o objeto POST PROCESSING no painel Objects.

![Selecione o objeto POST PROCESSING no painel Objects.](/img/guides/configure-depth-of-field/01_select-the-post-processing-object-in-the-objects-panel.png)

### Opcional: Adicione o componente DepthOfField

> Use esta seção somente se o componente ainda não estiver listado no painel Properties. Se ele já estiver presente, ignore as ações desta seção e continue com o tutorial principal abaixo.

2.1. Toque em Add Component para adicionar DepthOfField.

![Toque em Add Component para adicionar DepthOfField.](/img/guides/configure-depth-of-field/02_tap-add-component-to-add-depthoffield.png)

2.2. Abra a categoria Render.

![Abra a categoria Render.](/img/guides/configure-depth-of-field/03_open-the-render-category.png)

2.3. Abra a categoria Lens.

![Abra a categoria Lens.](/img/guides/configure-depth-of-field/04_open-the-lens-category.png)

2.4. Selecione o componente DepthOfField.

![Selecione o componente DepthOfField.](/img/guides/configure-depth-of-field/05_select-the-depthoffield-component.png)

**Fim da seção opcional. Continue com o tutorial principal abaixo.**

2. Selecione o componente DepthOfField para visualizar suas configurações.

![Selecione o componente DepthOfField para visualizar suas configurações.](/img/guides/configure-depth-of-field/06_select-the-depthoffield-component-to-view-its-settings.png)

As configurações de 3. DepthOfField estão visíveis em Properties.

![As configurações de DepthOfField estão visíveis em Properties.](/img/guides/configure-depth-of-field/07_depthoffield-settings-are-visible-in-properties.png)

## Resultado

O componente DepthOfField está configurado e suas opções estão visíveis no painel Properties. Você pode ajustar os valores e visualizar o resultado na cena.
