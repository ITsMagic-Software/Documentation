# Como configurar Outline

Este guia mostra como configurar o componente Outline no objeto POST PROCESSING. Siga os passos abaixo e ajuste as configurações para obter o resultado desejado na cena.

## Passos

1. Selecione o objeto POST PROCESSING no painel Objects.

![Selecione o objeto POST PROCESSING no painel Objects.](/img/guides/outline/01_select-the-post-processing-object-in-the-objects-panel.png)

### Opcional: Adicione o componente Outline

> Use esta seção somente se o componente ainda não estiver listado no painel Properties. Se ele já estiver presente, ignore as ações desta seção e continue com o tutorial principal abaixo.

2.1. Toque em Add Component para adicionar Outline.

![Toque em Add Component para adicionar Outline.](/img/guides/outline/02_tap-add-component-to-add-outline.png)

2.2. Abra a categoria Render.

![Abra a categoria Render.](/img/guides/outline/03_open-the-render-category.png)

2.3. Abra a categoria Highlights.

![Abra a categoria Highlights.](/img/guides/outline/04_open-the-highlights-category.png)

2.4. Selecione o componente Outline.

![Selecione o componente Outline.](/img/guides/outline/05_select-the-outline-component.png)

**Fim da seção opcional. Continue com o tutorial principal abaixo.**

2. Selecione o componente Outline para visualizar suas configurações.

![Selecione o componente Outline para visualizar suas configurações.](/img/guides/outline/06_select-the-outline-component-to-view-its-settings.png)

As configurações de 3. Outline estão visíveis em Properties.

![As configurações de Outline estão visíveis em Properties.](/img/guides/outline/07_outline-settings-are-visible-in-properties.png)

## Resultado

O componente Outline está configurado e suas opções estão visíveis no painel Properties. Você pode ajustar os valores e visualizar o resultado na cena.
