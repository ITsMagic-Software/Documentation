# Crie seu jogo com a ITsMagic Engine

Bem-vindo à documentação oficial da **ITsMagic Engine 2.0**.

Se você está abrindo a engine pela primeira vez ou procurando uma classe específica, esta documentação ajuda a encontrar rapidamente o próximo passo. Comece por um guia, aprenda os conceitos da engine ou vá direto para a referência da API.

## Um caminho simples para aprender

Se você está começando agora na ITsMagic, siga esta ordem:

1. [Crie um projeto vazio](./guides/creating-your-first-project) ou comece a partir de [um template](./guides/creating-a-project-from-a-template).
2. Aprenda o fluxo básico em [Primeiros Passos](./getting-started).
3. Leia os [Conceitos](./concepts) relacionados ao que você está construindo.
4. Use a [Referência da API](./api-reference) quando precisar dos detalhes de uma classe ou método.

:::tip Comece pequeno

Você não precisa aprender a engine inteira antes de construir algo. Crie um projeto, faça uma pequena alteração, execute-o e use a documentação para responder à próxima dúvida.

:::

## O que você pode criar

A ITsMagic reúne cenas, objetos, componentes, física, interface, áudio, materiais, programação visual e scripts em Java ou Lua em um único fluxo de trabalho. A documentação está organizada para que você aprenda esses sistemas gradualmente e depois consulte as páginas de referência quando precisar de detalhes técnicos exatos.

Se não encontrar o que precisa, use a busca ou acesse a [Comunidade](./community/contributions) para encontrar informações de ajuda e contribuição.
