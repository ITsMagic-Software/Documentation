# Referência da API (Java, Lua)

As APIs do runtime estão organizadas aqui por categoria para scripts em Java e Lua.

- Se uma classe Java estende `Component`, ela aparece em `Referência da API/Components`, com a categoria indicada como `"<Categoria>"`.
- As outras classes Java aparecem em `Referência da API`, com a categoria indicada como `"<Categoria>"`.
- Classes sem categoria ficam em `Uncategorized`.
